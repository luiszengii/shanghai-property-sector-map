# 上海房地产“板块”来源与独立绘制方案

> 核对日期：2026-07-22
> 研究对象：`map.hfwgsj.com` 页面所展示的约 121 个上海房地产板块，以及可替代的公开或可授权来源。
> 边界：本轮只核对公开页面、正式报告、官方规划与数据许可；没有登录目标站、没有下载或保存目标站板块坐标，也没有使用本地小红书语料。

## 结论先行

截至核对日期，**没有发现一份公开、可直接复用、同时满足以下四项的文档或数据集**：

1. 与目标站完全一致的 121 个板块名称；
2. 每个板块的完整定义或“四至”描述；
3. 121 个板块的面边界数据；
4. 允许复制、改编、公开发布或商业使用的明确许可。

当前最接近的候选有两套，但都不能直接当作目标站的数据源：

- **城市测量师行 / RVMS 口径**：2021、2022 年公开研究报告各列出完整的 121 个上海住宅租赁监测板块名称，但没有公开每个板块的边界、定义或可复用许可。目标站保留标签与这套名单严格匹配的只有 50 个，因此“数量同为 121”不足以证明同源。
- **中指院口径**：一份 2025 年券商报告称上海大约有 202 个板块，其中只有 121 个有房价数据，并在附录列出这 121 个名称。这里的“121”是**有数据的子集**，不是完整板块宇宙；报告也没有提供边界几何或复用许可，而且它是券商报告对中指院数据的转述，不是中指院发布的公开标准。

因此，项目有三条可行路线：

| 目标 | 最稳妥的路线 | 能否与目标站完全一致 |
|---|---|---|
| 要目标站那套边界 | 向目标站运营方取得书面数据许可和交付文件 | 只有获得授权后才能确认 |
| 要一套行业研究口径 | 向城市测量师行或中指院购买/申请板块字典、定义与空间数据授权 | 可能接近，但未必相同 |
| 要合法、可解释、可维护的自有地图 | 以官方规划和行政边界为证据，结合开放许可道路、水系、铁路等要素独立绘制 | 可达到很高的几何精度，但不能声称等同目标站 |

**推荐采用第三条路线，并把第一、第二条作为并行的授权询价。** 我们可以把边界画得精细、拓扑严密、每条边有出处；但在没有同一套定义或原始几何的情况下，无法保证“语义上与对方一模一样”。

## 事实、观察和推断

为避免把线索写成结论，以下三类信息分开记录。

### 已确认事实

- 上海的“楼市板块”不是一级法定行政区划。官方可稳定查到的是区、街道、镇、乡，以及总规、单元规划、控制性详细规划和专项规划等不同层级的规划范围。
- 目标站的[服务协议](https://map.hfwgsj.com/fwxy.html)标示运营主体为安徽微观信息科技有限公司，并限制未经书面许可的复制、转载、抓取、衍生利用和商业使用。即使前端能看到或网络请求能返回数据，也不等于获得了再利用许可。
- 城市测量师行研究报告确实列出 121 个监测板块名称；报告版权页要求未经许可不得转载，未附空间数据开放许可。
- 2025 年中银证券《解密上海楼市》写明“上海板块无官方划分，大约可分为 202 个板块，其中 121 个板块有房价数据”，附录价格数据来源为中指院。该报告没有发布板块面边界。
- 上海“详细规划一张图公众版”可以按地址或地块编号查看规划名称、批文号、用地性质、容积率等信息，但页面没有提供整套房地产板块 GeoJSON/SHP 下载。

### 对目标站页面的有限观察

此前只保留了页面标签统计，没有重新获取其面坐标：

- 页面共 121 行；
- 去重后 118 个值；
- 其中有 9 行是 `1` 至 `6` 一类数字占位值；
- 去掉数字占位后有 112 个唯一非数字名称。

这说明页面上的“121”首先是当前前端行数，不一定代表 121 个已完成、唯一、正式命名的板块。

### 尚不能确认的推断

- 目标站可能综合了多个行业口径，再由人工拆分、合并或重命名；目前没有公开证据能证明具体上游来源。
- 一些目标站标签与城市测量师行或其他房产平台近似，但近似命名不能证明边界相同。
- 目标站的边界可能是人工描绘，也可能来自商业数据库；未获得运营方说明前不能断言。

### 商业地图和房产平台的技术结论

- **高德最值得做一次受控验证，但不是现成可下载的数据源。** `biz_area + extensions=all` 在接口能力上最接近商圈 polygon。验证应只检查上海返回量、名称、是否有边界、是否稳定，不把结果批量保存为项目数据。若覆盖合适，再向高德申请允许缓存、改编和公开展示的书面许可。
- **百度与腾讯公开文档中的“商圈”字段不等于商圈面。** 百度 `business` 和腾讯 `business_area` 可帮助判断项目所在商圈，但没有形成可下载的全市板块边界；AOI 又是商场、园区等单体兴趣面，与房地产板块不是同一概念。
- **链家/贝壳的约 212 个次级区域更像一套完整命名字典。** 它能解释为什么目标站会出现许多细粒度、街镇化名称，但 `212 ≠ 121`，且没有来源证据证明两者同源。即使名称高度相似，也不能把页面目录或隐藏接口批量复制到自有数据库。
- **OSM/Nominatim 只能返回 OSM 中已经存在的对象。** `suburb`、`quarter`、`neighbourhood` 可能只是点，也可能边界不完整、互相重叠；它不是完整房地产板块体系。公共 Nominatim 服务不允许系统性枚举，批量研究应使用合法的 OSM extract 或自建实例，并遵守 ODbL。

## 两套“121”与目标站的关系

### 1. 城市测量师行 / RVMS 的 121 板块

可核对的报告为：

- [《上海存量住宅租赁市场：租赁需求收缩、挂牌增加，三季度末上海住宅租赁市场开始转入淡季》](https://pdf.dfcfw.com/pdf/H3_AP202112011532231549_1.pdf)，城市测量师行，2021-12-01；完整名单在 PDF 页脚 06–07。
- [2022 年后续报告](https://pdf.dfcfw.com/pdf/H3_AP202208021576801332_1.pdf)再次列出同套完整名单，页脚 06–07 的图表更清楚。

注意：以上 PDF 当前通过第三方证券资讯镜像访问，不是权利人的原始下载页。报告末页声明版权归城市测量师行，未经许可不得转载。

城市测量师行官网确认其具备 [RVMS、GIS 和数字系统开发](https://www.surea.com/szhxtkf/)能力，因此它是值得直接询价的上游候选；但官网没有公开这 121 个板块的 GIS 下载页。

#### 严格名称比对结果

以目标站此前保留的 121 行标签，对报告 121 名单做严格匹配，只统一了空白并移除名称末尾的“板块”二字：

- 严格交集：50 个；
- 占目标站 121 行的 41.3%；
- 占目标站 112 个非数字唯一名称的 44.6%。

可见差异包括：

| 目标站示例 | 报告示例 |
|---|---|
| 陆家嘴 | 陆家嘴滨江 |
| 世博、世博滨江 | 浦东世博 |
| 古美 | 古美罗阳 |
| 梅陇、春申 | 梅陇春申 |
| 淞南、高境 | 淞南高境 |
| 安亭 | 安亭汽车城 |
| 松江新城 | 松江新城东区、松江新城西区 |
| 嘉定老城 | 嘉定主城区 |

这些差异包含拆分、合并和重命名，意味着即使两个系统都写“121”，空间含义也可能不同。**不能把 RVMS 名单直接当作目标站边界说明。**

### 2. 中指院“约 202 中的 121 个有价格数据板块”

[中银证券《解密上海楼市》](https://pdf.dfcfw.com/pdf/H3_AP202509101741024178_1.pdf?1757498060000.pdf=)发布于 2025-09-10：

- 页脚 38：说明上海板块没有官方统一划分，大约可分为 202 个，其中 121 个有房价数据；
- 页脚 46 起：列出这 121 个有价格数据的板块，并另列无数据板块；
- 报告的数据来源栏将板块房价数据归于中指院。

因此，这份材料证明的是一种“约 202 的大目录 + 121 个有数据子集”的研究口径，**不能证明存在一套名为“官方 121 板块”的当前标准**。它也不是中指院一手发布的板块规范，不能替代商务授权。

中指官网目前明确提供：

- [CREIS 中指数据库](https://www.cih-index.com/product/zhdatabase)：住宅、土地、规划、POI 等专业数据；
- [中指数据 API](https://api.cih-index.com/)：面向机构客户，按模块订阅，并可提供定制数据；
- [API 使用指南](https://api.cih-index.com/pages/%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97.html)：测试和正式调用均需联系客户经理，正式使用在完成订单后取得密钥，并配置 IP 白名单。

公开 API 介绍没有承诺提供上海板块 polygon。询价时应明确问“板块字典与边界”，不能只问“上海房价数据”。

## 官方材料能解决什么、不能解决什么

官方材料不能替我们给全市市场板块下一个统一定义，但能给独立绘制提供高质量证据。

### 可直接采用正式范围的板块

对具有法定或正式规划含义的功能片区，应优先采用批复、公示或专项规划的范围。例如：

- [张江科学城建设规划](https://ghzyj.sh.gov.cn/ghgs/20200110/0032-719773.html)明确写出北至龙东大道、东至外环—沪芦高速、南至下盐公路、西至罗山路—沪奉高速，总面积约 94 平方公里；
- [虹桥国际中央商务区及周边地区专项规划](https://ghzyj.sh.gov.cn/ghjh/20250821/21759aa7efb34d49887951dc3c4da32a.html)提供正式规划附件；
- 前滩、北外滩、临港等区域也应按对应的控制性详细规划、专项规划或管理范围逐一核对，而不是按房产网站截图估线。

同名并不必然同范围。比如“张江科学城”“张江镇”“房产平台的张江板块”是三个可能不同的空间对象，数据模型中必须区分。

### 可作为基线但不能直接等同板块的材料

- 16 区行政边界；
- 现行街道、镇、乡边界；
- 单元规划和控制性详细规划范围；
- 道路中心线、河道、铁路、高速、外环等稳定地物；
- 轨道站点、商业中心和生活圈等辅助要素。

现有官方行政边界研究详见 [《上海官方行政区边界数据调研》](./OFFICIAL-SHANGHAI-ADMIN-BOUNDARIES.md)。其中已确认：国家天地图可生成上海 16 区 GeoJSON，但用途被限定为地图可视化；全市现行街镇面尚未发现无需申请即可下载的同版官方 GIS 数据。

## 不建议采用的“捷径”

1. **抓目标站前端响应再保存 polygon**：技术上可见不等于有复制与再发布权，且目标站条款已有明确限制。
2. **对着目标站、房产平台或商业底图截图描边**：生成的坐标仍可能是受限数据的实质性改编，难以证明独立创作。
3. **把标准地图 PDF 的路径直接转成 GeoJSON**：PDF 缺少可靠的 GIS 属性、行政代码和坐标参考，转换后也不能称为官方 GeoJSON。
4. **把街镇边界改名为楼市板块**：一个板块可能跨街镇，一个街镇也可能拆成多个板块。
5. **仅凭 ArcGIS 服务公开可访问就认定可商用**：公开访问和开放许可是两件事。已核查的 `neighbourhoodshanghai` 图层只有 16 个区，且元数据没有来源或许可。
6. **因同为 121 就认定同源**：目标站与 RVMS 严格名称匹配不足一半；中指院的 121 又是有价格数据子集。

## 推荐的数据模型

名称来源与几何来源必须分开，不能只留一个 `source` 字段。建议每个板块至少保存：

```text
id
canonicalName
aliases[]
districtIds[]
townIds[]
kind                       # official_functional_zone | planning_unit | market_sector | manual_research
geometry
centroid
crsOriginal
crsDisplay
boundaryBasis[]            # 每条边依道路/河流/行政线/规划线的说明
nameSources[]
geometrySources[]
licenseRecords[]
validFrom
reviewedAt
version
confidence                  # high | medium | low
status                      # draft | reviewed | published | retired
disclaimer
independentlyAuthored
```

其中 `boundaryBasis[]` 建议细到每一段共享边：

```text
edgeId
basisType                   # official_plan | admin_boundary | road | river | railway | manual_rule
featureName
sourceUrl
sourcePublisher
sourcePublishedAt
sourceCheckedAt
decisionNote
```

板块可能跨区或跨街镇，因此使用 `districtIds[]`、`townIds[]`，不要强制单一上级。

## 独立绘制的证据等级

| 等级 | 边界依据 | 使用方式 |
|---|---|---|
| A | 正式规划批复、官方“四至”、获授权的官方矢量 | 直接作为主依据，记录文件版本和有效日期 |
| B | 官方行政区/规划图、可复核的道路河流铁路 | 按文字规则独立重建，并由第二人复核 |
| C | OSM 等开放许可矢量 | 满足署名和 ODbL 要求后作为几何要素；与官方图交叉检查 |
| D | 多家市场平台形成的名称共识、人工访谈 | 只帮助命名或决定拆分逻辑，不复制平台边界；标记中低置信度 |

发布时应明确写“房地产市场研究边界，非行政区划、非规划法定界线”。

## 分阶段绘制流程

### 阶段 0：冻结词典，不先画线

1. 先决定自有分类目标：是 121 个、约 202 个，还是以产品实际需要为准；不要为了追求与他站相同数字而硬凑。
2. 为每个候选板块建立名称卡：规范名、别名、所属区/街镇、正式功能区关系、拆分/合并争议。
3. 将纯数字占位、重名、同名异义全部处理后再进入绘图。

### 阶段 1：先做 12 个试点板块

1. 优先选择有清晰规划或稳定地物边界的板块；
2. 每个板块填写一张“边界决策表”，四条边分别写依据；
3. 在 QGIS 中以共享边为单一要素绘制，相邻面引用同一条边，避免分别手画产生缝隙；
4. 保留原始坐标系、转换参数和处理日志；
5. 通过试点确定命名、证据和授权门槛，再按区批量扩展。

### 阶段 2：按行政区成批扩展

推荐顺序：

1. 中心城区中边界证据较明确的正式功能片区；
2. 与街镇或清晰道路河流高度对应的外围板块；
3. 争议较大的市场板块；
4. 跨区、滨江、产业走廊和新城复合板块。

每批都做名称评审、几何评审、许可评审，不等全市画完才返工。

### 阶段 3：拓扑和法律验收

几何检查至少包括：

- 自相交、空几何和环方向；
- 相邻板块缝隙、重叠、碎片和极细长面；
- 共享边坐标完全一致；
- 与上海市域、区界和水域关系合理；
- 跨区板块的上级关联完整；
- centroid 是否落在面内，必要时另存 label point；
- 坐标系转换前后抽样偏差。

许可检查至少包括：

- 名称、描述和几何分别有来源；
- 每个来源记录核对日期和许可；
- 没有从受限网站派生坐标；
- 需要署名或共享同许可的成果已满足条件；
- 授权文件覆盖缓存、改编、公开展示、下载和商业使用等实际场景。

## 决策建议

现阶段可以直接进入“稳妥绘制”，但要把目标改成：

> 建立一套具有可追溯名称体系、独立边界规则、清晰许可和版本记录的上海房地产研究板块，而不是无证据地复刻某站 121 个面。

第一批继续使用项目已有的 12 个板块作为试点最合适。对于每个试点，先完成名称卡和四边依据，再画 polygon；只有证据达到 A–C 级且许可可接受时才进入发布。与此同时发出三组授权询价。如果后续拿到合法的行业或目标站数据，可作为对照或经许可替换，而无需推倒现有数据模型。
