# shfang.xyz 大陆访问性能快照

测试时间：2026-07-26（Asia/Shanghai）

目标：https://shfang.xyz/

源站：腾讯云首尔轻量应用服务器 `43.155.217.8`

## 结论

网站在大陆三网总体可用，但速度属于“可用、波动明显”，不是低延迟大陆站点的水平。ITDOG 174 个大陆节点中 172 个成功，成功请求总耗时中位数为 2.10 秒，P95 为 3.93 秒；移动优于电信和联通。当前主要瓶颈是大陆到首尔的跨境连接与动态 HTML TTFB，而不是 HTML 体积。高德地图资源本身来自大陆服务，但在应用首屏完成后仍会继续加载到约 4.4–6.1 秒。

## 优先级建议

1. **优先在大陆边缘缓存公开首页和静态资源。** 对纯公开、无 Cookie 的首页可考虑腾讯云 CDN/EdgeOne；先确认域名备案与大陆加速资格。预期收益主要是消除跨境 TLS 和大部分静态资源往返。
2. **给 Nginx 开启 HTTP/2。** 这是低风险优化，可减少并发小资源在 HTTP/1.1 下的连接与排队开销，但不能消除跨境 TTFB。
3. **减少首页动态渲染。** 如果首页内容不依赖用户态，可改为静态生成/增量静态生成，或在 Nginx/边缘对匿名 HTML 设置短时缓存；变更前要确认 RSC、查询参数和实时数据语义。
4. **延后非关键预取与地图附加请求。** 当前页面会预取 `/sector-editor`，高德地图资源会持续到约 6 秒；可在首屏稳定后再做非关键路由预取和次要图层加载。
5. **上线后做真实用户监测。** 收集按省份和运营商拆分的 LCP、INP、TTFB，比单次实验室快照更能反映实际体验。

## 测试边界

- 本报告是单日快照，不代表全天高峰或所有省份。
- 当前客户端的系统代理/TUN 会影响路由，因此没有把本机 DNS/TCP 毫秒数用于结论。
- ITDOG 不执行完整页面渲染，三网统计必须与 Chrome 页面加载数据分开解读。
- ITDOG 不保留本次公开历史结果页；报告记录了测试时间、节点数、统计口径和失败节点，后续需要长期审计时应在登录状态下导出原始结果。
