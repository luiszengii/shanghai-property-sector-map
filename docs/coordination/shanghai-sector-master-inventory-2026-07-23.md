# 上海楼市板块主清单与绘制盘点

更新日期：2026-07-24

## 口径

本清单不再以“121 个板块”为目标。上海楼市板块没有官方统一数量；本项目采用版本化身份库，综合：

1. 环二先生《[一句话讲清上海各个板块](https://zhuanlan.zhihu.com/p/495825270)》所用的街镇、贝壳和民间共识混合口径；
2. [上海链家公开网站地图](https://sh.lianjia.com/seositemap/)的二级商圈名称，用于查漏和别名核对；
3. [上海市民政局街道、镇、乡名单](https://mzj.sh.gov.cn/MZ_zhuzhan1539_0-2-8-1459/20250701/13c356554a0a4634b311b7aeb10d1918.html)，只用于行政名称和隶属关系核对；
4. 已由用户裁定并独立重建的市场候选面。

文章和卖方目录只用于身份研究，不复制其图片或边界。行政街镇也不自动等于楼市板块。

## 中央注册表接入规则

1. `src/data/sectors/registry.json` 仍是运行时唯一身份表；
2. 先登记稳定身份，再绘制边界；没有几何时必须使用 `geometry.status = "missing"`；
3. 跨区功能板块记录多个 `districtNames`，不能按单一区界裁切；
4. 别名不生成独立 polygon；
5. 主清单更新导致新增、合并或拆分时，必须记录 ADR，不能为了维持 205 这个数字而保留错误身份；
6. 前滩—杨思拆分、黄浦十板块、浦东东南九板块、青浦—松江—金山三十板块、徐汇十二板块、长宁阶段批次、静安—普陀十一板块、虹口—杨浦首批七块、鞍山／中原代理、中远两湾城／甘泉宜川成对候选、宝山首批八块、嘉定首批八块，以及奉贤八块现行代理已经进入中央拓扑；奉城身份已登记但因旧开放关系仍含头桥而保持几何缺失。后续批次仍需同步更新运行时注册表、候选几何与逐边证据，避免瞬时不一致。
