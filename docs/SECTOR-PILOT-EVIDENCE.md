# 上海楼市板块首批 12 个试点：边界证据表

> 2026-07-23 最新口径：`sector_qiantan` 已恢复为独立“前滩”一级板块，新增 `sector_yangsi`；杨思采用原合并候选面扣除前滩后的差集。本文以下 Z000801 / ES4 证据重新用于前滩一级候选。详见 [ADR-0022](adr/0022-split-yangsi-and-qiantan-primary-sectors.md)。

> 核对日期：2026-07-22
> 对象：`src/data/sectors.geojson` 中现有 12 个演示板块。
> 目标：先确定名称含义和每条边的证据，再进入几何绘制；本文件不是最终 GeoJSON，也不把市场板块冒充行政区或法定规划范围。

## 结论

这 12 个名称不能直接按同一种规则画：

- **前滩、北外滩**有现行或仍被官方沿用的正式规划四至，可以先按官方功能片区口径建立高置信度草图。
- **徐汇滨江、大宁**有官方四至，但公开材料存在不同空间口径，或官方功能区与楼市板块未证明等同；必须先选择版本。
- **张江、金桥、三林、北蔡、古美、莘庄、徐泾、虹桥商务区**都存在“市场称呼、街镇、开发区、科学城、城市副中心或商务区”不等范围的问题。现有证据足够说明它们在哪里、与哪些正式区域相关，却不足以直接发布市场板块面。
- 现阶段**没有任何一个板块取得可直接复用的官方 Polygon**。即使文字四至完整，也应使用有明确许可的道路、河流和行政线独立重建，而不是从政府 PDF、商业地图或房产网站描摹路径。

因此，第一轮可直接进入边界规则草拟的只有 **前滩、北外滩**；徐汇滨江和大宁需先做一次口径决定；其余 8 个继续保持 `draft`。

## 证据等级和状态

| 标记 | 含义 |
|---|---|
| A | 市或区政府批复、正式规划文本、现行行政区划公告中的明确范围或边界段 |
| B | 政府部门公开的规划、街镇概况或相邻关系，可定位但不能独立还原全部边界 |
| C | 具备开放许可的道路、河流、铁路等几何；使用 OSM 时须遵守 ODbL |
| `reviewed-high` | 名称含义已冻结，文字边界足以独立重建，仍需取得或制作合规几何 |
| `draft-medium` | 有高质量正式范围，但板块名称与该正式范围是否等同尚需项目决策 |
| `draft-low` | 名称存在多义，或只有部分边界证据；不得据此补画闭合面 |

## 逐板块证据

### 1. 前滩

- **建议规范名**：`前滩（Z000801 单元 / ES4）`
- **可记录别名**：前滩地区、前滩国际商务区。
- **正式功能关系**：黄浦江南延伸段前滩地区，控规单元编号 Z000801；市政府文件也称 ES4 地块。
- **可确认边界**：
  - 北：川杨河；
  - 南：中环线华夏路段；
  - 东：济阳路；
  - 西：黄浦江。
- **面积证据**：约 2.83 平方公里；控规公示写 283.17 公顷。
- **证据等级**：A。
- **状态**：`reviewed-high`。可以按这套正式功能片区口径建立边界规则，不应再扩大到新杨思、三林或其他被市场宣传为“前滩辐射”的区域。
- **剩余缺口**：四条边仍需从合规数据源取得几何；黄浦江岸线和川杨河边界应确定取岸线、河道中心线还是规划蓝线，中环线应确定道路红线还是中心线。正式四至只解决语义，尚未解决几何规则。
- **来源**：
  - [黄浦江南延伸段前滩地区（Z000801 单元）控制性详细规划附加图则公示](https://ghzyj.sh.gov.cn/ghgs/20200110/0032-560351.html)
  - [上海市政府《黄浦江两岸地区发展“十三五”规划》](https://ghzyj.sh.gov.cn/ghjh/20200110/0032-723689.html)
  - [浦东新区政府关于前滩国际商务区绿色生态城区专业规划的批复](https://www.pudong.gov.cn/zwgk/assets/zfgb-pdf/2019%E7%AC%AC%E4%B8%89%E6%9C%9F%60.pdf)

### 2. 徐汇滨江

## 可执行的绘制顺序

### 第一组：先建立正式功能片区边界规则

1. **前滩**：采用 Z000801 / ES4 四至。
2. **北外滩**：采用 2020 年市政府批复四至。
3. **徐汇滨江**：产品确认采用 7.4 或 9.4 平方公里口径后再加入。
4. **大宁**：静安区确认 2017 年 10.92 平方公里范围仍适用，并确认产品接受“环大宁”口径后再加入。

### 第二组：先冻结语义，不画闭合面

- 张江：镇 / 94 平方公里旧科学城 / 220 平方公里新科学城 / 市场板块。
- 金桥：镇 / 自贸片区 / 经开区 / 城市副中心 / 市场板块。
- 三林、北蔡、古美、莘庄、徐泾：街镇范围还是市场范围。
- 虹桥商务区：带版本的核心区、86.6 平方公里原范围还是 151.4 平方公里现行范围。

### 几何来源规则

- 官方 PDF、在线规划图只作为边界文字和空间关系证据；在没有明确矢量再利用许可时，不从图面提取坐标。
- 道路、河流、铁路可以优先使用 [OpenStreetMap](https://www.openstreetmap.org/copyright) 的开放数据重建，但必须署名；公开衍生数据库时还要评估 ODbL 的共享同许可义务。
- 2025 年浦东街镇界线调整涉及北蔡—张江、金桥—张江、北蔡—康桥。任何旧版街镇面都必须先验证版本，不得直接接入。
- 每一条共享边只存一份几何，相邻板块引用同一个 `edgeId`；道路边必须统一中心线、红线或街坊边线规则，河流边必须统一中心线、岸线或蓝线规则。
