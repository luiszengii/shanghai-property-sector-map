# 奉贤先生成 8 个现行行政代理并暂缓奉城

状态：接受（2026-07-24）

主清单中的西渡、南桥、奉贤金汇、海湾、柘林、奉城、四团、青村、庄行均有卖方市场身份，也分别能对应一个现行同名街镇；但行政同名不证明精确楼市边界。本批因此只把西渡、南桥、奉贤金汇、海湾、柘林、四团、青村、庄行 8 项登记为 `draft-low`、`internal_review` 的可编辑行政起画代理。

奉城暂缓。2024 年 7 月官方从奉城镇析出 38.4 平方公里设立头桥街道，而固定 OSM 快照内没有头桥街道 relation，名为奉城镇的 relation `17885593` 面积约 109.8578 平方公里，仍与调整前约 110.63 平方公里口径相符，不能证明已扣除头桥。为凑齐九块而继续使用该旧面会把过期行政边界冒充 2026 现行代理；本批明确拒绝，并把奉城保留为待取得现行开放边界或可复算头桥差集后的缺口。

海湾暂以完整海湾镇 relation `17885597` 起画。固定快照内海湾旅游区 relation `17885592` 完全嵌套其中，但卖方单一“海湾”标签没有公开其是否按旅游区、滨海大学城或完整镇域分类。因此既不擅自扣除旅游区，也不把该内部重叠解释成市场范围已经核准；注册表和逐边证据必须保留 `unresolved_haiwan_tourism_area`。

南桥不等于跨南桥、奉浦、金海及相邻镇部分区域的奉贤新城；“奉贤金汇”保留市场显示名，行政代理名单独记录为金汇镇。头桥、奉浦、金海及海湾旅游区可成为显式未分配或内部未决范围，不能为了行政铺满而自动分给相邻市场。
