# ADR 0023：黄浦九板块采用同名街道骨架起画

- 状态：已接受
- 日期：2026-07-23

## 背景

下一批需要在不复制商业地图 polygon 的前提下，一次增加 5–10 个可解释、可编辑、拓扑连续的楼市候选面。

黄浦区主清单中的瑞金二路、打浦桥、五里桥、半淞园路、老西门、小东门、豫园、外滩、南京东路九个市场身份，与现行街道名称一一对应。固定 OSM 上海快照包含九个完整街道 relation；相邻 relation 复用同一组边界节点，适合构建无重叠共享拓扑。上海市民政局名录和 2025 年黄浦区标准地图可以核对名称、隶属、形状和邻接，但不提供本项目坐标。

“新天地”没有采用同样处理。它是市场功能片区，与淮海中路街道并非简单同义；若机械套用街道关系，会重复此前被用户指出的“看起来很假”的问题。

## 决定

1. 新增九个互斥一级市场候选：瑞金二路、打浦桥、五里桥、半淞园路、老西门、小东门、豫园、外滩、南京东路。
2. 每个候选使用固定 OSM 快照中的同名街道 relation 作为保守几何骨架，记录 relation ID、快照哈希和 ODbL 署名。
3. 九个候选进入同一个 0.1 米拓扑组；同源 relation 原始共享边必须保持至少 250 米，最大拓扑位移不得超过 0.1 米。
4. 行政骨架只是一版可解释起点。候选统一标记为 `internal_review`，允许用户在板块编辑器中按完整小区归属继续修改。
5. 市民政局名录与天地图标准图只作名称、邻接和视觉核验；不从 PDF 或商业地图提取坐标。
6. 淮海中路与新天地留到后续独立语义批次，不用未完成的第十块强行填满黄浦区。

## 结果

- 本批九个候选全部为有效单 Polygon；
- 候选之间面积重叠为 0；
- 已声明的最短共享边约 294 米；
- 九个候选相对锁定 relation 的拓扑位移均为 0 米；
- 项目精确候选总数由 13 增加到 22。

这些结果证明几何和拓扑可复现，不证明市场语义已经成为行业统一标准。
