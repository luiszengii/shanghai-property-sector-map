# 板块身份登记与边界几何解耦

`src/data/sectors/registry.json` 是板块身份、名称和定义状态的唯一登记表。板块可以先登记、后绘制边界；此时 `geometry.status` 为 `missing`，不得为了满足数据结构而伪造占位面。

板块编辑器必须按登记表生成列表。已有几何的登记项载入可编辑副本，没有几何的登记项显示为“待绘制”，首次绘制仍沿用同一个稳定板块 ID。主地图只渲染能够解析出有效几何的登记项，不渲染 `missing` 项。

GeoJSON、候选面和行政参考面都是登记身份的可选几何实现，不再反向决定“有哪些板块”。数据校验要求每个几何 Feature 都有登记身份，但允许登记表包含尚无几何的板块。
