# 下线“梅园”独立市场身份

状态：接受（2026-07-28）

## 决策

按用户对现有卖方板块目录的复核结果，从活动板块注册表中删除 `sector_meiyuan`（梅园），并同步移除其覆盖性编辑种子、小红书无样本映射和当前地图覆盖。

历史研究中对“梅园”一词的提及继续保留，但不再据此维护独立、闭合的活动楼市板块。相关资料不得改名或迁移到陆家嘴、源深等相邻板块。

## 理由

- 当前没有独立候选面或可复算的市场四至。
- 活动几何只是自动生成的覆盖性编辑椭圆，不是用户裁定边界。
- 现有登记主要来自单一卖方目录，并存在名称歧义，缺少其他板块数据的交叉支持。
- 该身份没有授权小红书样本。

## 迁移

- 历史研究文档和已保存版本继续保留。
- 若浏览器中存在以 `sector_meiyuan` 为来源的草稿，编辑器将其归档为只读 `referenceOnly` 备份，不参与导出或主页地图覆盖。
- 当前生效覆盖移除该身份；后续保存也会过滤所有未登记身份。
