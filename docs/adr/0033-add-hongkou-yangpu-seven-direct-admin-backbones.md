# 新增虹口—杨浦 7 个直接同名市场行政骨架

日期：2026-07-24

状态：已采纳

## 决定

为以下 7 个市场身份新增低置信、可编辑的行政对齐候选面：

- 虹口：四川北路、曲阳、凉城、江湾镇；
- 杨浦：控江路、五角场、新江湾城。

链家上海网站地图只用于确认这些公开市场名称；虹口、杨浦区政府资料用于确认同名或稳定简称对应的现行街道身份和面积量级；几何采用项目固定日期 OpenStreetMap relation 作为起画骨架。

全部候选保持：

```text
reviewStatus = draft-low
confidence = low
publicationPolicy = internal_review
method = market_admin_candidate_with_shared_topology
```

不宣称行政街道等于卖方专有边界或行业统一楼市边界。

## 名称映射

- 曲阳 → 卖方简称“曲阳” → 曲阳路街道；
- 凉城 → 卖方简称“凉城” → 凉城新村街道；
- 江湾镇 → 江湾镇街道，现行行政类型是街道而不是镇。

注册表保留正式行政名作为别名，避免道路、历史镇名、市场简称和现行街道身份混淆。

## 专项风险

- 四川北路保留 `post_2018_north_bund_reorganization_review`，后续复核 2018 年北外滩区划调整是否被卖方市场同步采用；
- 五角场保留 `area_mismatch_review_required` 与 `mixed_non_residential_scope`。固定 OSM 面积约 7.4055 平方公里，比官方 7.66 平方公里少约 3.32%，且完整街道混合高校、园区、商业和住宅；
- 新江湾城保留 `mixed_water_green_campus_scope`，完整街道包含大量水绿、校园和非住宅空间。

## 明确保留的覆盖缺口

本批不自动注册：

- 虹口：瑞虹新城、鲁迅公园；
- 杨浦：东外滩、鞍山、定海路、黄兴公园、中原。

这些身份需按功能片区、卖方项目成员或相邻市场联合裁切，不用行政残余自动填满。

## 验收

- 7 个 relation 唯一，名称严格匹配；
- 固定 OSM 候选总面积约 30.5907 平方公里；
- 7 面彼此及与接入前 92 个中央候选零面积重叠；
- 6 组同批行政邻接线采用完全相同的坐标序列；
- 每个候选进入注册表、逐边证据和编辑器；
- 新江湾城沿用批次 D 已有本地 XHS 样本；其余 6 个只登记无样本缺口，不生成观点或代表来源。
