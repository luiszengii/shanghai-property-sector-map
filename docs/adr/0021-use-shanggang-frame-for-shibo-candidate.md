# 世博候选面采用上钢新村街道框架

世博一级楼市板块采用用户选择的“方案 1”起画：以上钢新村街道公开文字范围和固定日期 OSM relation 作为定位骨架，西、北临黄浦江，南至川杨河；东侧与上南共享边南起川杨河、北止浦东南路—白莲泾，北端以后沿 2025 年世博场馆红线调整段接黄浦江。候选面覆盖后滩、世博园、耀华、上钢这一连续市场语义。

生成时，世博候选面在最多 60 米的声明连接距离内接入 ADR-0022 拆出的杨思和上南候选面，并以相邻候选面的共享线为优先，消除一级板块间的缝隙和重叠。上南候选面也以相同方法贴合杨思；60 米是两份开放骨架之间允许建立共享线的最大间距，不是把两侧各外扩 60 米。最终输出必须通过无面积重叠、连续共享边和最终锚点覆盖校验。前滩作为独立一级板块，在南侧另与三林共同总装。

上钢新村街道只是稳定、可复核的起画框架，不等于市场世博，也不构成法定行政界址。上南路等分隔式道路和场馆红线段仍须按完整小区或项目归属逐段核验；任何修正都必须同步更新共享边两侧。

2023 年上钢新村街道资料给出的 7.54 平方公里早于 2025 年周家渡—上钢局部界线调整，只保留为历史量级参考。生成器对调整后的世博候选面采用宽松安全面积区间，不把 7.54 平方公里标为现行官方面积或用作硬误差基准。
