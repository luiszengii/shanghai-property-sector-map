# 新增宝山八个同名街镇低置信候选

日期：2026-07-24

## 决定

1. 新增顾村、张庙、淞南、高境、杨行、罗店、月浦、罗泾 8 个一级市场身份的低置信可编辑候选。
2. 每块只以固定 OSM 快照中的同名现行街镇行政关系作为起画骨架，保持 `confidence = low`、`reviewStatus = draft-low`、`publicationPolicy = internal_review` 和 `marketAdminAlignmentUnverified = true`。
3. 同批 8 面使用同一固定快照总装，必须零面积重叠；所有声明相邻关系必须保持完全相同的共享坐标序列。
4. 淞南—新江湾城及高境—江湾镇／五角场／新江湾城的跨区行政骨架共享边必须复算，不得因分批生成产生缝隙。
5. 同批相邻候选的共享拓扑关系进入编辑器草稿；人工修改任一方后，导出前必须逐对提示相关共享边需要联合复核。
6. 顾村、淞南、杨行、罗店、月浦、罗泾完整镇域明显过宽，必须显式保留产业、铁路、乡村、生态及其他非住宅范围风险。
7. 大华、上大、南大、共康、淞宝不随本批自动生成。它们不能诚实地映射为单一同名街镇，也不得用本批之外的行政余量自动补齐。
8. 顾村沿用已有真实小红书采集样本；其余 7 块只登记“地图已有、当前无样本”的缺口，不生成空观点、代表来源或事实结论。

## 理由

上海市民政局现行街镇名录确认宝山区存在张庙街道以及顾村、淞南、高境、杨行、罗店、月浦、罗泾 7 镇。固定 OSM 快照中 8 个同名 `admin_level8` 关系均唯一、有效且互斥，面积从张庙约 4.7558 平方公里到月浦约 48.5951 平方公里不等，能够提供可重复生成的行政骨架。

但楼市板块不是法定行政区。尤其顾村、杨行、罗店、月浦和罗泾等完整镇域远大于连续住宅市场，并包含显著非住宅空间。本批的价值是建立可编辑、可审计且拓扑连续的起画层，不是把镇界宣称为精确市场边界。

完整来源、关系 ID、面积和共享边验收门槛见 `docs/research/baoshan-eight-direct-admin-aligned-boundary-evidence-2026-07-24.md`。
