# 新增长宁 4 个直接同名市场板块行政骨架

日期：2026-07-24

状态：已采纳

## 决定

为新华路、天山、仙霞、北新泾新增 4 个低置信、可编辑市场候选面。几何分别以固定日期 OpenStreetMap 的新华路街道、天山路街道、仙霞新村街道、北新泾街道关系为起画骨架，统一标记为 `draft-low`、`confidence = low`、`internal_review`，不宣称行政街道等同楼市板块。

本批只处理可直接映射的 4 个市场身份。中山公园、虹桥、古北、西郊不得自动注册：

- 中山公园存在官方道路围合与商圈范围，不能套用华阳路或周家桥任一街道；
- 古北位于虹桥街道内部，虹桥与古北必须作为互斥市场面同包裁切；
- 后续长宁住宅“虹桥”保留并必须使用独立 ID `sector_changning_hongqiao`，不得复用既有虹桥商务区 `sector_hongqiao`；
- 西郊跨程家桥、新泾镇，并与既有虹桥商务区存在空间冲突，必须另行联合总装；
- 江苏路、华阳路、周家桥、程家桥、新泾镇是行政事实，但当前不是可自动补入的一级市场身份，保留明确覆盖缺口。

## 拓扑约束

- 新华路—天山、天山—仙霞两组共享边必须使用完全相同的坐标序列；
- 北新泾暂为独立骨架，西侧与南侧待西郊批次联合复核；
- 全局候选保持零面积重叠；
- 既有 74 个候选几何不得因本批生成发生变化；
- 生成、目录同步与证据写入必须可重复执行且结果确定。

## 后续

1. 按官方道路围合和市场项目归属重建中山公园；
2. 先冻结古北四至，再从虹桥街道候选中扣除古北；
3. 联合程家桥、新泾镇、北新泾和既有虹桥商务区裁定西郊。
