# 古北与长宁住宅虹桥采用互斥候选

古北采用长宁区政府引用《古北新区开发规划》给出的文字四至独立重建：东姚虹路、西虹许路、北虹桥路及延安西路西段、南古羊路。官方 136.6 公顷只作面积量级校验；固定日期 OSM 道路线用于生成可复算的内部候选坐标，不把官方网页解释成可再分发 GIS 数据。

长宁住宅“虹桥”使用独立 ID `sector_changning_hongqiao`，不得复用既有虹桥商务区 `sector_hongqiao`。第一版候选按固定 OSM 虹桥街道行政骨架扣除古北候选生成，与古北严格互斥。官方材料只证明古北新区位于虹桥街道内；“虹桥街道减古北”是本项目的低置信市场候选推导，不是官方发布的虹桥住宅边界。

本批不把 2022 年“虹桥—古北商圈”或 2024 年“虹桥—古北商业中心地区”混入两个一级市场面，也不据此冻结虹桥与天山、仙霞的外部市场边。古北按 `medium / internal_review` 登记，住宅虹桥按 `low / internal_review` 登记，二者继续在边界编辑器中接受完整小区归属精修。

生成与发布门槛：

1. 古北面积须在官方 1.366 平方公里的 5% 范围内；
2. 古北四侧必须达到声明的 OSM 道路覆盖长度；
3. 长宁住宅虹桥须明确记录扣除 `sector_gubei`；
4. 两块面积重叠不得超过 0.01 平方米，并保留连续共享边；
5. `sector_hongqiao` 必须继续表示虹桥商务区，名称和几何不得被本批改写。
