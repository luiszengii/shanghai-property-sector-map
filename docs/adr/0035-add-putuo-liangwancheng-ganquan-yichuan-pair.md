# 成对新增中远两湾城与甘泉宜川低置信候选

日期：2026-07-24

## 决定

1. 新增“中远两湾城”独立一级市场身份。候选严格并集固定 OSM 快照中 5 个名称为“中远两湾城”或“中远两湾城西区”的 `residential` 用地面，保留 5 个分离组成面，不做凸包、缓冲、补缝或单面化。
2. 新增“甘泉宜川”低置信可编辑候选。它只取甘泉路街道与宜川路街道固定行政关系的并集，再扣除同批中远两湾城候选。
3. 两者必须保持零面积重叠和完全一致的 5 组差集共享边；差集与被扣项目重组行政并集的误差不得超过 1 平方米。
4. 中远两湾城是“官方身份与成员明确、开放项目用地可复算、官方 polygon 缺失”的项目代理，不是居委会法定 GIS 边界。
5. 甘泉宜川是行政最大包络余量，不是精确市场边界。光新接口、铁路及非住宅范围尚未解决，必须保持 `draft-low`、`confidence = low`、`internal_review`。
6. 恢复或人工修改中远两湾城后，不得静默把不匹配的甘泉宜川差集当成仍然有效；后续发布前须联合更新两者拓扑。
7. 边界证据不得伪装成四条笼统方位边：中远两湾城的 5 个 OSM 用地分片分别登记组件证据，甘泉宜川分别登记 2 个行政包络组件和 5 个共享扣除洞。

## 理由

普陀区政府 2008 年批复和 2026 年居委会设置表持续确认中远两湾城第一至第四居民区及中潭路、远景路成员范围；宜川路街道概况也明确南部新城区包含中远两湾城。固定 OSM 快照中的 5 个同名住宅用地面全部位于宜川路街道内，原样并集面积约 0.3674 平方公里，可作为不伪造连续外轮廓的起画层。

卖方“甘泉宜川”横跨甘泉、宜川语义，但两街道简单并集会吞并独立中远两湾城。扣除项目代理后约 4.2060 平方公里的余量拓扑守恒，适合进入编辑器继续裁切；官方宜川居委表同时显示光新村及多组光新路地址仍位于该余量中，因此不能把几何闭合误称为市场定稿。
