# 杨思前滩作为主板块并保留前滩子范围

状态：已由 ADR-0022 取代。2026-07-23 用户改为前滩、杨思两个独立一级板块。

本项目的主板块采用“杨思前滩”，市场候选四至为北川杨河、东春塘河、南中环路—华夏西路、西黄浦江。官方约 2.83 平方公里口径、按开放地物重建为约 2.93 平方公里的“前滩”不再代表完整主板块，而作为杨思前滩内部的官方参考子范围保留；该身份由链家分类、安居客四至和用户裁定独立支持，不依赖复刻受限平台清单。固定 OSM 快照中拟作东界的两段水线没有名称，在取得能把它们与春塘河直接绑定的证据前，只能作为可编辑候选线；南侧分隔式道路当前也只确认到与中环路—华夏西路走廊 15 米内贴合，尚未证明为唯一共享中位线。两侧都不能标记为已核验。
