# 新增鞍山与中原低置信行政代理，拒绝用残余街道填满其余五块

日期：2026-07-24

状态：已采纳

## 决定

新增两个仅限内部复核的可编辑起画面：

- 鞍山：固定四平路街道 relation `13466002`；
- 中原：固定殷行街道 relation `13466582` 内，按固定 OSM 军工路对象裁取道路中心线以西住宅连续区。

两者均保持：

```text
reviewStatus = draft-low
confidence = low
publicationPolicy = internal_review
```

鞍山不是同名行政映射，只因公开卖方正例高度集中在四平路街道而采用异名代理；中原则有杨浦区政府“殷行街道所在的中原地区”直接语义支持，且政府材料明确区分军工路以西住宅区和以东企事业单位集聚区。本轮明确拒绝把完整殷行街道当成中原。

## 明确不生成

本轮不为以下 5 个市场身份生成完整行政面或行政并集：

- 瑞虹新城：官方资料只证明瑞虹各期位于嘉兴路街道，不能证明完整嘉兴路街道等于瑞虹市场；
- 鲁迅公园：需要在四川北路、欧阳路、广中路接口联合裁切，不能把欧阳—广中完整并集自动升级；
- 东外滩：公开语义同时涉及杨浦滨江功能区、周家嘴路住宅带及平凉—大桥—定海滨江子集，不能用完整街道并集；
- 定海路：行政街道同名，但公开卖方目录未形成稳定同名市场，且完整街道包含复兴岛和产业滨江；
- 黄兴公园：官方四至只确认约 39.86 万平方米公园本体；住宅市场需在长海路、延吉新村等接口裁切，不能使用整街道并集。

零重叠、完整覆盖或“正好填满行政区”不能替代市场身份和项目归属证据。

## 专项风险

- 鞍山候选约 2.6433 平方公里，对应四平路街道完整行政面；同济校园、非住宅范围及江浦路接口需精修；
- 中原候选约 4.6819 平方公里，由完整殷行街道约 9.6129 平方公里裁取军工路以西部分；军工路以东企事业单位集聚区已明确排除。官方材料另载街道约 7.98 平方公里，说明行政面积版本仍有差异，西侧内部也仍需按完整小区归属精修。
