# 下线“闵行金汇”独立市场身份

状态：接受（2026-07-28）

## 决策

按用户对现有卖方板块目录的复核结果，从活动板块注册表中删除 `sector_minhangjinhui`（闵行金汇），并同步移除其覆盖性编辑种子和小红书无样本映射。

“金汇华光城”等公开成员定位仍作为历史研究证据保留，但不再据此推导一个独立、闭合的“闵行金汇”楼市板块。相关资料不得改名或迁移到金虹桥、龙柏、虹桥或奉贤金汇。

## 理由

- 当前没有可复算的独立市场四至或闭合范围。
- 现有官方资料只确认虹桥镇内的社区或成员定位，不证明独立卖方板块身份。
- 该身份没有已保存的编辑器边界、当前生效覆盖面或授权小红书样本。
- 保留一个无法在其他卖方板块目录中复核的活动入口，会增加与金虹桥、龙柏和奉贤金汇的误识别风险。

## 迁移

- 历史研究文档继续保留，作为“曾研究但未进入活动目录”的记录。
- 若旧浏览器中存在以 `sector_minhangjinhui` 为来源的草稿，编辑器将其归档为只读 `referenceOnly` 备份，不参与导出或主页地图覆盖。
- 已有版本文件不做追溯性重写；当前核对未发现该身份的已保存草稿或生效覆盖面。
