# 中山公园先登记官方道路围合核心

中山公园不套用华阳路、江苏路或周家桥任一完整街道。第一版采用沪绿容〔2022〕104 号给出的“中山公园地区”道路围合：东华阳路与安西路、南安化路、北万航渡路、西中山西路—长宁路—凯旋路。固定日期 OSM 道路线只用于独立重建可复算坐标，不从官方图件或商业平台提取边界。

该面登记为 `sector_zhongshangongyuan`、`medium / internal_review`，约 1.0727 平方公里，产品名称仍为“中山公园”，但定义、说明和别名必须明确它是“核心候选”。它不能被解释为完整楼市中山公园，也不能把核心之外的江苏路、华阳路或周家桥剩余区域静默并入。

生成与发布门槛：

1. 四侧道路身份和固定 OSM 对象必须完整进入 manifest；
2. 最终边界须在 15 米容差内达到各侧声明覆盖长度；
3. 面积须保持在 0.7—1.5 平方公里的安全量级；
4. 新增本候选不得改变此前 80 个候选几何；
5. 西郊继续保持未登记，直到完成程家桥—新泾镇—北新泾—仙霞—虹桥商务区联合裁定。
