# 西郊在官方骨架闭合门槛失败后继续留白

“西郊”已由链家网站地图、链家项目页、房天下分类页和信义项目页交叉确认是长宁实际使用的二级市场身份，但现有公开证据仍不足以复建完整楼市四至。

《长宁区公园城市规划（2024—2035 年）》图 4-20 给出约 2.55 平方公里的“西郊样板区”，并标注天山西路、新泾港、金浜路和外环绿道等骨架。该对象是公园城市样板区，不是楼市边界；图件只能用于识别稳定地物，不能反描或反算坐标。

本轮使用固定 OSM 快照逐一核对这些命名地物后，四侧线网不能形成唯一闭合面：天山西路在外环接口存在开放数据缺口，金浜路与外环附近也不能在声明容差内闭合。按研究门槛，不用直线、任意缓冲、地址凸包或 PDF 图面补口。

同时否决以下两个替代方案：

1. 不把程家桥街道、新泾镇、北新泾街道并集扣除保护面后的约 14.8186 平方公里残余面命名为西郊；
2. 不把外环—天山西路—北虹路/威宁路—虹桥路形成的宽面，仅凭有噪声的卖方点样本升级为完整西郊。

因此：

- `sector_xijiao` 本轮不进入注册表、候选 GeoJSON 或编辑器已有板块；
- 程家桥、新泾镇未分配区域继续保持显式覆盖缺口；
- 现有北新泾、仙霞、长宁住宅虹桥和虹桥商务区几何不因本研究改变；
- 后续只有在补齐第一卖方交叉样本、逐边相邻归属和唯一闭合线网后，才能生成低置信、可编辑的西郊候选。

完整样本、反例、公式与生成门槛见 `docs/research/changning-xijiao-market-boundary-evidence-2026-07-24.md`。
