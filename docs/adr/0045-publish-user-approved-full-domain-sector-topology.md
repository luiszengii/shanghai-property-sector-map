# Publish the user-approved full-domain sector topology

On 2026-07-30 the repository owner explicitly instructed the project to
publish the current full-domain topology version that had previously been
available only as the local repair preview.

The production geometry is generated by
`scripts/build-project-topology-repair.py` with an explicit approved version
and approval timestamp. The tracked outputs are:

- `src/data/sectors/published-topology.wgs84.json`;
- `src/data/sectors/published-topology.index.json`;
- `src/data/sectors/published-topology.manifest.json`.

This is a user-approved market-research topology, not a statutory,
administrative, planning, cadastral, or official boundary. The geometry uses
the fixed `osm-geofabrik-shanghai-260728` Geofabrik/OpenStreetMap snapshot and
existing project candidate geometry. The user-authorized RealtyNavi snapshot
may inform sector-name ownership and adjacency decisions, but none of its
coordinates are included in the tracked output.

The published topology is the highest-priority production geometry layer.
Earlier candidates and editor overrides remain as source history and fallback
inputs; they do not override this approved version. A later production
topology must use a new approval identifier, regenerate all three files, and
pass the public-surface hash, identity, coordinate, and topology checks.

The approved version intentionally contains 190 polygon features for 197
registered identities. Seven identities do not own a separate polygon in this
version because their land is assigned to another approved polygon. This does
not create uncovered land in the approved Shanghai target domain.
