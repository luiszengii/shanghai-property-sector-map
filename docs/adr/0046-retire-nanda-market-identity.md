# 下线“南大”独立市场身份

状态：接受（2026-07-28）

## 决策

按用户对现有板块目录的复核结果，从活动板块注册表中删除 `sector_nanda`（南大），并同步移除其覆盖性编辑种子、W12-1301 规划参考代理、小红书无样本映射和当前地图覆盖。

W12-1301 “南大地区”仍是可核验的规划和地理语境，但不再作为独立住宅市场板块身份。它不会自动改名或并入上大、顾村、杨行、桃浦等相邻市场；未被其他已裁定市场边界覆盖的范围明确保持待归属。

## 理由

- 最新保存版本中的南大草稿与载入时的规划代理指纹一致，没有人工修边。
- 该代理来自跨宝山、普陀且产居混合的控详规划范围，不是住宅市场裁定面。
- 活动身份的独立市场范围始终处于阻断状态，没有正式候选面。
- 该身份没有独立授权的小红书样本。

## 迁移

- 历史研究文档、规划来源和下线裁定时已有的 25 个保存版本继续保留；后续版本也沿用同一归档规则。
- 浏览器中的 `sector_nanda` 草稿由编辑器归档为只读 `referenceOnly` 备份，不参与导出或主页地图覆盖。
- 三个现有楼盘的“南大”所在地标签继续保留，板块归属等待单独核验，不据本次身份删除自动改派。
- 当前生效覆盖移除该身份；后续保存也会过滤所有未登记身份。
