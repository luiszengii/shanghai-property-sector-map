# 闵行先生成四个现行镇代理并暂缓三个阻断身份

状态：接受（2026-07-24）

主清单中七宝、华漕、梅陇、颛桥、马桥、吴泾、浦江镇均有已核验的市场身份；上海市行政目录也可确认对应镇级名称。行政同名不足以证明卖方边界，本批只将七宝、梅陇、颛桥、马桥登记为 `draft-low`、`internal_review` 的可编辑行政起画代理。

华漕、吴泾、浦江镇均不生成候选面。固定 OSM 华漕镇 relation `14187985` 与既有徐泾市场候选重叠约 1.98 平方公里；保护既有徐泾后，自动总装需要超过 1.15 公里的非局部位移。吴泾对梅陇、颛桥、华泾做保护性差集会自相交；浦江镇完整镇域则横跨既有三林、康桥、周浦、航头和奉贤金汇候选。三种问题都不是短共享边或坐标精度问题，任何自动残余面都缺乏可解释的市场语义。因此三者已进入注册表、保留来源和人工绘制入口，但状态为 `market_identity_verified_geometry_blocked`，禁止发布旧镇面或扭曲后的残余面。

梅陇、颛桥和七宝与既有古美、莘庄、春申候选的局部交叠，采用声明的保护性差集，以既有市场候选的坐标序列作为共享边；这只解决编辑器候选间的零面积重叠，并不把行政代理升级为精确市场边界。

静安新城、闵行金汇、龙柏、航华、金虹桥、老闵行均非可直接替代的同名现行镇，已登记为 `market_identity_verified_geometry_blocked` 的可人工起画身份而不生成面。尤其航华涉及七宝镇和新虹街道的原航华地区，必须按独立市场身份联合研究，不得吞入七宝镇；闵行金汇也不得与奉贤金汇合并。
