# 前滩与杨思拆成两个一级板块

用户裁定不再使用“杨思前滩”作为一个一级主板块。前滩与杨思分别登记为互斥一级市场板块：

- 前滩沿用 Z000801 / ES4 官方四至候选，由固定日期 OSM 道路、水系和岸线独立重建；
- 杨思严格取原“杨思前滩”市场四至候选面扣除前滩候选面的差集；
- 被扣除的前滩部分不得同时出现在杨思，也不得为了视觉连续性重分给三林；
- 小于 100 平方米、由线位叠加产生的数值碎片不作为独立市场板块部件保留；
- 两者都是内部复核候选，不宣称法定规划坐标或商业平台边界。

该裁定取代 ADR-0014 的“杨思前滩主板块 + 前滩内部子范围”方案。行政参考层继续独立保存，不替代市场板块。
