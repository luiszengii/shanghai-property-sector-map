# 纠正静安—普陀剩余市场身份并拒绝行政填空

日期：2026-07-24

状态：已采纳

## 决定

静安—普陀剩余 12 个主清单名称不作为一批同名行政面直接生成。几何零重叠只能证明现有候选没有相互覆盖，不能证明楼市板块语义正确。

本轮作出以下裁定：

1. 石门二路、宝山路、芷江西路、共和新路只保留为可复现的行政覆盖参考，不登记为已完成的市场板块；
2. 彭浦新村街道 relation 不等于卖方“彭浦”。已有卖方项目样本越过官方街道东界，因此拒绝直接生成；
3. 不夜城与苏河湾只允许依据 2017 年官方东西功能片区四至成对生成低置信历史功能候选；2021 年约 4.2 平方公里苏河湾总功能区只作上级参考范围，不冒充卖方苏河湾；
4. 阳城—永和拆成阳城、永和两个市场身份，完成双方项目成员和共享边研究前不画合并面；
5. 武宁、光新已经通过市场名称门槛，但公开范围不能唯一闭合；不得从曹杨、石泉完整行政面机械截取；
6. 真光按官方 17 个居委成员拼接，取得成员边界前不得复制真如或长征完整行政面；
7. 新增中远两湾城市场身份；甘泉宜川以甘泉路、宜川路两街道并集为最大研究包络，但必须先扣除中远两湾城并核对光新接口，不能把简单并集登记为市场边界；
8. 长征继续保留为明确标注的低置信行政代理；它不替代卖方市场中远两湾城。

## 理由

当前主清单混合了行政街道、官方功能片区和卖方住宅市场。把行政关系填满空白会形成拓扑整齐但语义错误的“假精确”：

- 链家现行静安目录使用镇宁路、西藏北路、闸北公园、彭浦等市场名，而非石门二路、宝山路、芷江西路、共和新路、彭浦新村这五个行政名；
- 临汾小区被归入卖方彭浦，但地址位于官方彭浦新村街道东界岭南路以东；
- 中远两湾城位于宜川路街道内，却是独立卖方市场，因此甘泉路与宜川路的行政并集必然过宽；
- 2021 年苏河湾总功能区包含 2017 年不夜城西部片区，不能同时作为两个互斥市场面。

## 后续顺序

1. 不夜城—苏河湾按 2017 年历史功能片区成对重建；
2. 阳城、永和按两个身份联合裁切；
3. 真光取得 17 居委几何后与真如、长征一起重建；
4. 新增中远两湾城身份，再裁切甘泉宜川；
5. 武宁、光新补足社区成员或项目正反例后联合重建。

未通过上述门槛的区域继续在地图上显示为明确覆盖缺口；不得通过扩大相邻候选或填充行政残余掩盖。
