# 500–800 万新盘真实位置核验（2026-07-22）

## 结论与使用边界

- 本文只核验项目名称、行政区/板块和项目地块位置，不核验清单中的价格、优劣势、学校或规划描述。
- 优先级为：政府规划/房管/地名/教育公开文件、开发商或上市公司披露、项目正式页面/地图 POI。第三方楼盘页只用于补足已编门牌或交叉核对，不单独支撑项目身份。
- “项目地址”指住宅地块或已编住宅门牌，不是城市展厅、样板间、售楼处或接待中心。若项目包含多个地块/门牌，地图只能显示一个点时，应使用项目整体几何中心或明确标为“主地块代表点”。
- 置信度：**高**＝政府/开发商一手资料能把项目与地块或正式门牌连起来；**中**＝一手资料确认地块、第三方资料补足门牌；**低**＝只有二手交叉验证或仍存在同名/营销名歧义。
- 所有链接访问日期均为 **2026-07-22**；各来源自身日期写在链接说明中，未显示发布日期的记为“页面无日期”。
