# 宝山 8 个同名市场的行政骨架证据

日期：2026-07-24

对象：顾村、张庙、淞南、高境、杨行、罗店、月浦、罗泾。

## 结论

这 8 个名称既是链家上海公开网站地图中的宝山二级市场名，也能稳定映射到现行同名街镇：张庙对应张庙街道，其余 7 项对应同名镇。项目固定 OSM 快照中也各有一个名称严格匹配、几何有效的行政 boundary relation。

因此，8 项都可作为 `confidence = low`、可编辑的 `market_admin_candidate_with_shared_topology` 起画骨架；**没有一项可称为精确楼市边界、官方市场边界或行业统一边界**。其中张庙、月浦、罗泾的 OSM 面积与官方口径差异明显，淞南也有约 3.78% 差异；完整镇域普遍包含大量产业、铁路、乡村、水域或生态空间。

大华、上大、南大、共康、淞宝不得在本批中生成、替代或静默并入这 8 个行政骨架。它们没有一一对应的同名现行街镇 relation，必须另做项目归属和市场四至研究。

## 一、证据口径

### 1.1 市场身份

[链家上海网站地图](https://sh.lianjia.com/seositemap/)列出本批 8 个宝山二级市场。该目录只用于确认市场名称存在；本研究没有获取、复制、反推或再分发链家的专有边界、坐标或房源全集。

### 1.2 现行行政身份

[上海市政府宝山区页面](https://www.shanghai.gov.cn/baoshan/index.html)列明宝山区现辖街镇。其中张庙是街道；顾村、淞南、高境、杨行、罗店、月浦、罗泾均为镇。市场显示名与正式行政名应分字段保存，不能省略正式行政类型后把名称相同误写成边界相同。

## 三、逐块建议与风险

### 顾村

名称与行政身份稳定、面积吻合，可作起画骨架。但 `41.66 km²` 镇域远大于连续住宅市场，包含乡村、产业和交通空间。南侧与大华、上大、南大、共康等市场语义交错；不得为铺满地图而把这些市场静默吸收。升级前须用完整小区归属共同重建顾村—张庙—杨行及南侧争议边。

### 张庙

唯一街道级候选，体量较小，但 OSM 比官方约小 `8.37%`，现行官方页面又缺完整四至。共康市场可能跨越或切入张庙及相邻行政单元。第一版必须标记 `area_mismatch_review_required`；未解释面积版本前不得升级。

### 淞南

官方四至较完整，适合作为行政骨架对照；但 OSM 比官方约大 `3.78%`，完整镇域含产业、铁路和非住宅空间。南侧需与新江湾城联合检查，北侧不得吞并淞宝。

### 高境

OSM 与官方面积接近，但官方现行页面只给“三区交界”的概述，没有逐边四至。与江湾镇、五角场、新江湾城及共康的市场接口均可能偏离行政线，应按完整小区验证，不能因面积吻合就提高置信度。

### 杨行

规划文字给出了北泗塘、蕰藻浜等稳定行政锚点，OSM 面积也接近官方；但约 `39.5 km²` 的完整镇域混合产业、铁路和非住宅空间。南大、淞宝不能并入，顾村—杨行—罗店—月浦共享边应成组维护。

### 罗店

面积与官方基本一致，行政邻接清楚，可作大尺度起画骨架。完整镇域同时包括新镇、老镇、乡村和产业区，住宅市场很可能需要明显收窄。不得把“石太路以南 `40.43 km²`”规划范围误作完整镇域或市场范围。

### 月浦

OSM 比官方约大 `7.27%`，且完整镇域工业功能显著。该面只能提供总装连续性，不能声称住宅市场已精确完成。升级前必须解释面积差异，确定宝钢、工业岸线和非住宅空间的展示规则，并与杨行、罗店、罗泾联合复核。

### 罗泾

OSM 比官方约小 `14.75%`，是本批最大偏差。行政范围还包含长江岸线、乡村、生态和产业空间。第一版即使生成也只能是低置信可编辑骨架；面积版本差异没有得到官方图或更强数据解释前，禁止升级。

## 四、明确禁止在本批生成的 5 个市场

| 市场 | 禁止处理 | 原因与后续要求 |
|---|---|---|
| 大华 | 不得以顾村、张庙或其他街镇整体替代；不得并入顾村 | 跨行政/市场语义，需完整小区正反例与相邻板块共享边 |
| 上大 | 不得从顾村镇或大场镇行政残余推断 | 没有一一对应的同名现行街镇 relation，需单独研究上大功能与住宅连续区 |
| 南大 | 不得并入顾村或杨行 | 规划功能区、历史地名和楼市市场可能采用不同范围，需独立四至证据 |
| 共康 | 不得并入张庙、高境或顾村 | 市场可能跨街镇/区界，需按完整小区联合划边 |
| 淞宝 | 不得并入淞南、杨行、月浦 | 复合市场身份不对应单一同名现行街镇，需独立核验淞宝与吴淞等接口 |

“禁止生成”只指不允许按本批直接行政映射规则自动生成，不表示这些市场不存在，也不表示其区域可以留给相邻 8 面永久覆盖。

## 五、生成与验收门槛

第一版统一使用：

```text
status = reviewed-candidate
confidence = low
method = market_admin_candidate_with_shared_topology
marketAdminAlignmentUnverified = true
```

生成必须满足：

1. 每个候选固定使用表中 relation ID、严格校验正式行政名，不允许模糊名称自动命中；
2. 产品显示名与正式行政名分开保存，特别是 `张庙 → 张庙街道`，其余 7 项保留正式类型“镇”；
3. 保存快照时间、GPKG SHA-256、OSM 面积、官方面积和面积差异；
4. 所有几何非空、有效、无自交；同批 8 面正面积重叠必须为 `0`；
5. 共享边按成组拓扑生成和编辑；修改任一相邻面后，另一侧须提示重新验证，不能静默制造重叠或缝隙；
6. 张庙、淞南、月浦、罗泾必须显示面积差异风险；罗泾在差异解释前禁止升级；
7. 顾村、淞南、杨行、罗店、月浦、罗泾必须显示“完整行政面明显可能过宽/混合非住宅空间”；
8. 大华、上大、南大、共康、淞宝保持显式未解决项，不得被本批覆盖状态掩盖；
9. 对外归因必须分开：政府资料证明行政身份和范围线索，链家目录证明市场名称存在，OSM 固定快照提供开放几何候选；
10. OSM 使用必须保留 ODbL 归因；政府规划图或天地图只能人工复核，不包装成可再分发官方 GeoJSON。

从 `low` 升级还必须逐块满足：

1. 至少取得分布在不同方向的多个卖方项目正例；
2. 每条争议边至少取得一个相邻市场项目反例；
3. 张庙、淞南、月浦、罗泾的面积差异得到可追溯解释；
4. 明确产业、铁路、乡村、水域、生态和大型公共设施是否保留在市场展示面；
5. 与同批相邻面及新江湾城、江湾镇、五角场等既有候选联合通过零重叠、共享边和覆盖缺口检查；
6. 至少第二类独立市场证据支持范围，不依赖单一卖方目录。

## 六、本研究明确不主张

- 不主张 8 个行政面就是链家或任何卖方的专有 polygon；
- 不主张名称相同就意味着市场边界和行政边界相同；
- 不主张面积接近能证明边界精确；
- 不主张 OSM relation 是法定行政界线；
- 不主张当前零重叠证明宝山市场已完整覆盖；
- 不主张完整镇域内的产业、乡村、岸线、生态和交通空间都属于住宅市场；
- 不主张大华、上大、南大、共康、淞宝不存在或应并入相邻骨架；
- 不主张本研究获取、复制或再分发了卖方专有边界数据。
