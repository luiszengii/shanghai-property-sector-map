# 高德 GeoHUB 自定义地图价格、授权与项目适配核查

> 核查日期：2026-07-31（Asia/Shanghai）
>
> 核查范围：只使用高德开放平台产品页、定价页、服务协议、FAQ 和开发文档等第一方资料。
>
> 项目目标：弱化细小道路和小商铺，强化大商圈、学校、大型医院、地铁线路和高架线路。

## 结论

**适合先用 GeoHUB 免费版做一轮 Web 底图样式验证，但不建议仅靠高德底图完成全部信息分级。**

- GeoHUB 自定义地图有 **免费版，¥0/月**；可创建 1 份样式、修改 42 种地图元素，并可在 Web / Android / iOS 调用。专业版为 **¥399/月**，可创建 20 份样式，增加全部基础模板、纹理、图片创建、智能配色和移动端 SDK 在线调用等能力；旗舰版需询价。[高德开放平台产品定价](https://lbs.amap.com/upgrade)
- 本项目目前是 Web 地图，只需要 1 份正式样式，也不需要纹理或移动端 SDK 在线样式，因此**没有证据表明必须购买 ¥399/月的专业版**。先用免费版足够合理。
- JS API 端支持对“兴趣点”按类别单独配置属性，因此自定义样式具备把普通商业 POI 整类弱化或隐藏、把教育医疗交通与商业分开处理的能力。[高德自定义地图 FAQ](https://lbs.amap.com/faq/maplab/mapstyle/call-map/51788) 但官方公开页没有列出免费版 42 项的完整清单，目标 POI 类别是否全部落在免费权益内仍需编辑器实测。
- 但官方公开材料没有说明可按 POI 的“规模、等级或重要性”设置阈值。即使能控制医疗、教育、商业类别，也不能据此承诺可以自动只显示“大型医院”“重点学校”或“大商圈”。
- 高德公开材料确认可定制“道路”，但没有公开完整的 42 项元素清单，也没有明确说明“高架道路”在样式平台中一定是独立于高速、城市快速路、主干道的可配置类别。因此细路弱化可行性高；“高架线路单独强化”仍需编辑器实测。
- 价格页出现“地铁设施”这一元素，FAQ 也确认 JS API 支持 POI 分类样式；但官方公开材料没有明确承诺普通地理底图中的**地铁线路几何**能作为一个独立元素自由设置线宽和颜色。地铁站/设施与地铁线应分开判断。

因此建议采用：

1. GeoHUB 免费样式负责底图减法；
2. 项目自有专题层负责“大型/重点”的确定性表达；
3. 地铁线路若要成为视觉主角，使用许可明确、版本锁定的线路几何，自行绘制 `Polyline` / GeoJSON 图层；
4. 商业化之前再处理技术服务许可，不要把 GeoHUB 免费样式等同于免费商业授权。

GeoHUB 套餐表另注明“一次服务使用即加载一次地图，程序生命周期内计算为一次；如超额联系高德定制套餐”。公开页面没有把这条与“JS 地图图面初始化”月配额的关系解释到足以做精确账单预测，正式放量前应提交工单确认。[高德开放平台产品定价 · GeoHUB 套餐补充说明](https://lbs.amap.com/upgrade)

## 目标样式能做到什么

### 能明确做到

#### 1. 弱化细小道路

高德自定义地图允许对道路等地图元素设置是否显示、颜色、描边颜色和不透明度；产品介绍把“道路”列为可定制类别。[高德自定义地图产品介绍](https://lbs.amap.com/product/mapstyle/m)

合理的第一版做法是：

- 高速、城市快速路、主干道保持较高对比度；
- 次干路降低颜色和线宽；
- 支路及道路文字进一步降低对比度，或在低缩放级别隐藏；
- 板块面透明度保持较低，避免再次盖住道路。

但是官方公开页面没有列出当前 42 种元素的逐项道路分级名称，上述分级需要在已登录 GeoHUB 编辑器中逐项核对后才能承诺。

#### 2. 按 POI 类别处理小商铺

官方 FAQ 明确：“兴趣点”按类别单独配置属性目前在 JS API 端生效。因此 Web 项目的自定义样式能够把商业 POI 与教育、医疗、交通 POI 分开处理。[高德自定义地图 FAQ](https://lbs.amap.com/faq/maplab/mapstyle/call-map/51788)

`Map.setFeatures()` 自身只能把底图分成 `bg`、`point`、`road`、`building` 四类，`point` 是全部兴趣点；它不能独立保留学校医院、关闭小商铺。按类别控制必须依赖 GeoHUB 自定义样式，或把 POI 全关后由项目自绘。[高德地图 JS API 2.0 自定义地图教程](https://lbs.amap.com/api/javascript-api-v2/guide/map/map-style)

公开材料没有列出免费版支持的全部 POI 子类，也没有说明“餐饮、购物、生活服务、酒店”等名称是否与编辑器当前分类完全一致。实际分类和免费权益需要登录后的编辑器验收。

#### 3. 教育、医疗、商业、地铁设施是平台能够识别的元素类别

高德 GeoHUB 价格页在“可配置纹理的地图元素”中列出教育体育、医疗卫生、商业场所、地铁设施；纹理是专业版/旗舰版权益，不能据此反推免费版也拥有这些元素的全部配置项。[高德开放平台产品定价 · GeoHUB 套餐明细](https://lbs.amap.com/upgrade)

结合 JS API 可按 POI 类别配置的 FAQ，可以确认高德样式系统具有类别级处理能力；但免费版是否能对这四类分别设置所有目标属性，仍需真实编辑器确认。

### 不能仅凭官方公开资料承诺

#### 1. 只显示“大型”医院、学校和商圈

官方说明的是按兴趣点类别配置，不是按床位、医院等级、学校层级、商场体量、商圈影响力或 POI 排名配置。默认地图会随缩放级别和标签避让显示较重要 POI，但公开文档没有提供可由开发者直接设置的“大型/重点”筛选阈值。

可靠方案是：

- 底图中关闭或低调处理医疗、教育和商业 POI；
- 项目自行维护经过许可和核验的“重点学校、大型医院、大商圈”清单；
- 用独立 Marker / Label / Polygon 层控制名称、层级、聚合和最小显示缩放级别。

#### 2. 把地铁线路作为稳定的主视觉线

“地铁设施”可以指站点、出入口、站区或区域面，不能自动证明 GeoHUB 暴露了地铁线的独立线宽、颜色和层级控制。高德另有“地铁图 JS API”，但官方将它定位为移动端 H5 地铁线路示意图，适合线路查询、站点和路线规划，不是当前普通地理底图上的现成真实地理线路图层。[高德地铁图 JS API 产品说明](https://lbs.amap.com/api/)；[地铁图 JS API 高阶开发指南](https://lbs.amap.com/api/subway-api/guide/advancedguide/advancedguide01)

本项目若要明确强化上海地铁线，最稳妥的是用许可明确、版本锁定的线路几何，作为独立专题线层绘制；高德自定义样式只负责把底图道路和普通 POI 退后。

#### 3. 单独识别并强化所有高架道路

自定义样式可以调整道路类别，但高德公开资料没有说明高架是否始终作为独立样式类别，也没有说明能否区分同一城市快速路的地面段和高架段。若编辑器只提供高速/快速路/主干道层级，强化后会同时影响相同等级的非高架道路。

第一轮应先强化“高速和城市快速路”并视觉验收；如果产品确实需要只强调高架，需另找许可明确的高架线路数据作为专题层。

## 推荐落地方案

### 第一阶段：免费版验证

1. 用 GeoHUB 免费版复制标准或远山黛基底，仅创建 1 份项目样式。
2. 路网按“高速/快速路 > 主干路 > 次干路 > 支路”降低视觉权重。
3. 尝试隐藏餐饮、零售、生活服务、酒店、景区等普通 POI，记录免费版实际开放的分类。
4. 尝试分别保留行政区名、地铁设施、教育和医疗类别；若免费版没有相应分类配置，就关闭全部底图 POI 并改用项目专题层。
5. 继续用项目自己的板块、新房和已核验设施图层。
6. 在上海全域、中心城区、板块和楼盘四个缩放档验收标签密度。

免费版如果能够完成这些步骤，就没有购买专业版的必要。

### 第二阶段：专题层强化

- 地铁线路：独立彩色线路图层，站点在适当缩放级别出现；
- 高架/快速路：若高德样式分类不够，独立线层；
- 大型医院、学校、大商圈：项目核验清单独立 Marker / Label；
- 楼盘：继续使用项目自己的已裁定楼盘资料，不使用高德“住宅小区”POI 替代。

### 购买专业版的触发条件

只有出现以下需求时，再考虑 ¥399/月：

- 需要超过 1 份样式，例如桌面/移动、白天/夜间或不同业务场景；
- 需要高级模板、图片创建、智能配色或纹理；
- 后续推出原生移动端，并需要移动端 SDK 在线调用自定义样式；
- 免费版编辑器实际锁住了本项目必须使用的高级能力。

专业版不会自动解决“大型医院”“大商圈”“地铁真实线路”“高架线路识别”等数据语义问题。

## 上线前必须确认

1. **运营用途**：以自然人个人研究学习，还是企业/商业产品运营；公开站点的个案应向高德工单确认。
2. **样式元素清单**：登录后的当前免费版是否能分别控制高速、快速路、主干道、次干道、支路、商业 POI、教育 POI、医疗 POI、地铁设施。
3. **地铁线和高架粒度**：样式编辑器中是否存在独立线类，而非仅站点或道路等级。
4. **计费统计**：GeoHUB 的“一次地图加载”和 JS 地图图面初始化是否为同一计费事件；以控制台和工单回复为准。
5. **地图合规**：GeoHUB 服务协议提示，使用其生成的互联网在线地图可能涉及地图审核义务；应保留高德来源、审图号和版权标识，不得移除底图归属信息。[高德开放平台 GeoHUB 服务协议](https://lbs.amap.com/pages/geohub-service-terms)

## 尚不透明处

本轮没有找到以下公开第一方信息：

- 当前免费版 42 种可修改元素的完整逐项清单；
- POI 是否可以按高德内部重要度、规模或等级设显示阈值；
- 上海地铁线是否在 GeoHUB 中作为独立线路元素开放；
- “高架道路”是否是独立于高速、快速路和主干路的样式类别；
- GeoHUB 样式地图加载是否存在单独于 JS 地图初始化配额的公开免费额度；
- 高德对 `shfang.xyz` 当前无收费公开研究站点的个案授权认定。

这些问题应通过登录后的样式编辑器实测和高德工单书面确认，不应从“免费版”或“按类别配置”反推。

高德仍可访问一份 2023 年更新的按日配额说明页，但它与当前按月配额和阶梯计费页面口径不同；本报告未用该旧页作预算依据，应以当前[基础服务计费页](https://lbs.amap.com/pages/base_service_price)和控制台实际额度为准。
