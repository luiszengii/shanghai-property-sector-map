# 静安、普陀 11 个楼市板块的同名行政骨架证据

日期：2026-07-24

对象：

- 静安：南京西路、静安寺、曹家渡、江宁路；
- 普陀：长寿路、曹杨、真如、长风、长征、桃浦、万里。

结论状态：这 11 个名称同时具有公开卖方市场身份和现行同名或稳定简称对应的行政单元，**可以直接生成 `low-confidence`、可编辑的行政骨架代理；名称对应只支持起画，不证明行政面与楼市板块完全同义，也不代表两区完整市场覆盖。**

## 三、为什么“市场同名 + 行政同名”仍不是市场定稿

这 11 项的证据链只证明：

1. 链家公开目录使用该名称作为二级市场身份；
2. 区政府页面确认存在同名或稳定简称对应的现行行政单元；
3. 固定 OSM 快照提供对应行政单元的可追溯开放几何。

它不能证明：

- 链家的内部商圈边线与行政边线重合；
- 其他卖方、买方或行业参与者采用同一四至；
- 行政单元内的产业、商业、乡村、交通或大型公共设施都属于同一住宅市场；
- 11 个候选已经覆盖两区全部住宅市场；
- OSM relation 是法定行政边界。

因此第一版公式只能是：

```text
市场候选骨架 =
  对应现行行政单元的固定 OSM relation

status = reviewed-candidate
confidence = low
method = market_admin_candidate_with_shared_topology
```

其中 `method` 是生成器和持久化数据使用的正式方法标识；“同名行政骨架代理”是它的产品说明，不另设一个与数据契约不一致的 method 值。该公式是项目建模规则，不是卖方或政府发布的楼市边界。后续项目级归属证据可以收窄候选，但不能因为同名就把第一版升级为 `reviewed`、`official_boundary` 或“行业统一边界”。

## 四、桃浦必须单列高风险

桃浦镇固定关系面约 `19.1581 km²`，显著大于本批其他单个候选。完整镇域包含产业、乡村及不同城市功能地域，链家使用“桃浦”市场名不能证明这些地域都属于同一住宅板块。

第一版可以保留完整桃浦镇作为可编辑骨架，但必须：

- 显示“桃浦镇行政骨架代理”，不能只显示“桃浦已定稿”；
- 在说明中明确面积偏大以及产业、乡村部分待收窄；
- 后续按住宅连续区、具体小区市场归属、稳定道路水系和相邻板块共享边联合重建；
- 允许明确覆盖缺口，不得为追求整镇铺满而保留明显非住宅区域；
- 与真如、长征、万里及宝山相邻候选做零重叠和共享边检查。

桃浦的风险不否定市场身份，只是否定“同名即可把完整镇域视为最终市场面”。

## 六、生成与验收约束

1. 11 项均使用新的稳定市场 ID；行政 relation ID 只进入几何追溯字段，不复用为市场 ID。
2. 产品显示名与正式行政名分开保存。尤其保留：
   - `曹杨` → `曹杨新村街道`；
   - `真如` → `真如镇街道`；
   - `长风` → `长风新村街道`；
   - `长征` → `长征镇`；
   - `桃浦` → `桃浦镇`。
3. 首版几何必须与固定 OSM relation 一致；不得根据链家名称猜测或反推平台边界。
4. 每个候选标记 `confidence = low`，说明中显示“同名行政骨架代理，不等于行业统一市场边界”。
5. 运行几何有效性、自交、空几何、多部件和面积检查；同批候选之间不得重叠，共享行政边允许。
6. 桃浦单独触发“大面积/非住宅混合”验收提示，不因脚本成功而自动升级状态。
7. 本批排除名称不得被静默并入 11 个候选；未覆盖区域应保留并显示研究原因。
8. 后续收窄任一候选时，必须同步核对相邻候选共享边，避免单边编辑产生重叠或缝隙。
9. 对外归因应同时区分：
   - 政府页面：行政身份；
   - 链家目录：市场名称存在；
   - OSM 固定快照：开放几何候选。

## 七、本研究明确不主张

- 不主张这 11 个行政面就是链家或任何卖方的专有商圈 polygon；
- 不主张市场同名与行政同名意味着边界完全一致；
- 不主张本批已经覆盖完整静安区、普陀区或两区全部住宅市场；
- 不主张桃浦镇完整行政面是最终桃浦住宅市场；
- 不主张被排除名称不存在或应并入相邻板块；
- 不主张 OSM relation 是法定行政界线；
- 不主张本研究获取、复制或再分发了任何卖方专有边界数据。

## 八、最终建议

现在可以把这 11 个 relation 生成一批低置信、可编辑的 `admin_aligned_market_backbone`。静安 4 项为完全同名；普陀 7 项中应保留正式行政全称和类型，尤其把“真如镇街道”准确记录为街道。桃浦虽可进入同批，但必须作为明显过宽的优先收窄对象。

本批只解决“哪些市场身份可以先用同名行政面起画”，不解决两区完整市场拼图。被排除的行政单元和市场/功能名称继续保留为显式研究缺口。
