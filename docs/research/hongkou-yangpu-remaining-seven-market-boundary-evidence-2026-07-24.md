# 虹口—杨浦剩余 7 个市场板块的联合边界证据

日期：2026-07-24

对象：

- 虹口：瑞虹新城、鲁迅公园；
- 杨浦：东外滩、鞍山、定海路、黄兴公园、中原。

## 一、执行结论

这 7 个名称不能统一按“同名街道 = 市场板块”处理。当前证据只支持：

1. **鞍山**：以四平路街道 relation 作为 `low-confidence`、可编辑行政代理；
2. **中原**：只生成“殷行街道 relation 在军工路以西的住宅子集”这一 `low-confidence`、可编辑代理，不能使用完整殷行街道面；
3. **瑞虹新城、鲁迅公园、东外滩、定海路、黄兴公园**：现阶段不生成完整市场面，保留为联合裁切任务。

| 市场 | 行政 relation 组合或最大包络 | 当前是否生成 | 核心理由 |
|---|---|---|---|
| 瑞虹新城 | 嘉兴路街道 [13462879](https://www.openstreetmap.org/relation/13462879) | **不生成** | 政府“瑞虹新城/环瑞虹”是嘉兴路街道内的项目和地区；公开卖方二级市场名是“临平路”，没有证据证明完整嘉兴路街道就是瑞虹市场 |
| 鲁迅公园 | 四川北路 [13462869](https://www.openstreetmap.org/relation/13462869) + 欧阳路 [13465959](https://www.openstreetmap.org/relation/13465959) + 广中路 [13466055](https://www.openstreetmap.org/relation/13466055) 的接口裁切区 | **不生成** | 公园四至只能确定核心锚点；卖方样本向同心路、恒业路延伸，不能用公园面或任一完整街道代替 |

| 中原 | 殷行街道 [13466582](https://www.openstreetmap.org/relation/13466582)，优先裁为军工路以西住宅区 | **生成裁切后的 low-confidence proxy；不生成完整 relation** | 政府明确“街道所在的中原地区”，卖方正例位于国和、殷行、工农；政府同时明确军工路以东是企事业单位集聚区 |

这里的“relation 组合”是**联合研究包络**，不是把多个街道简单求并集后当成市场面。

## 二、来源与固定几何

### 2.1 市场身份

[链家上海网站地图](https://sh.lianjia.com/seositemap/)当前列出鲁迅公园、东外滩、鞍山、黄兴公园、中原等二级市场。它列出的是“临平路”和“周家嘴路”，而不是“瑞虹新城”和“定海路”。

本项目主清单已经把：

- 临平路映射为瑞虹新城；
- 周家嘴路映射为东外滩。

这两项是项目产品口径，不能反过来声称是卖方原始命名，更不能由名称映射推出专有 polygon。

链家页面只用于确认公开市场名称和少量项目归属正例。本研究没有复制、抓取或反推卖方专有边界。

### 2.2 政府来源的作用

政府页面用于确认街道、功能区、公园、项目或地区的公开身份和四至。它们不证明楼市市场边界。

## 三、逐项证据与生成裁定

### 3.1 瑞虹新城

**证据。**

1. 虹口区政府将瑞虹新城描述为原虹镇老街更新后形成、分多期建设的大型社区，而不是一个现行街道（[虹口区政府：虹镇老街与瑞虹新城](https://www.shhk.gov.cn/xwzx/002006/20170926/b2474646-7ef1-4fef-951d-416d4208b89d.html)）。
2. 区政府明确嘉兴路街道“瑞虹地区总开发面积约 170 万平方米”，并使用“环瑞虹”治理品牌。这证明瑞虹位于嘉兴路街道，但没有给出完整住宅市场四至（[虹口区政府：环瑞虹美好嘉园](https://www.shhk.gov.cn/xwzx/002005/20250407/5725d575-c99b-4fef-8234-b5f71ccac7b4.html)）。
3. 政府资料明确安丘居民区下辖瑞虹新城二期、四期，说明瑞虹项目由街道内部居民区承载，不等于完整街道（[虹口区政府：安丘居民区](https://www.shhk.gov.cn/xwzx/002005/20230824/e71d30f2-0cd6-41ac-95f0-f1655baa130e.html)）。
4. 张江虹口园公开范围中的“瑞虹地块”采用天虹路—瑞虹路—虹关路—虹镇老街—飞虹路四至，但这是园区功能地块，不能替代住宅市场（[虹口区政府：张江虹口园范围](https://www.shhk.gov.cn/xwzx/002008/002008040/20230728/5dee74ee-c47e-4c93-9ed6-bc95187e2af3.html)）。

**裁定。** 不生成完整瑞虹新城市场面。嘉兴路街道 relation 13462879 只作为最大行政包络。若产品坚持显示“瑞虹新城”，下一版应按项目各期、环瑞虹居住区和相邻市场反例联合描边；不能直接把完整嘉兴路街道改名为瑞虹新城。

**共享边。**

- 西侧与四川北路、南侧与北外滩接口必须沿现有行政共边起查，再用项目归属收窄；
- 北侧与鲁迅公园/曲阳方向不能用一条任意直线封口；
- 瑞虹内部裁切后产生的嘉兴路街道残余，不得自动填给四川北路或鲁迅公园。

### 3.2 鲁迅公园

**证据。**

1. 政府确认鲁迅公园位于四川北路、甜爱支路一带，占地约 `28.63 ha`；这是公园本体，不是楼市市场（[虹口区政府：鲁迅公园](https://www.shhk.gov.cn/zjhk/001003/001003002/20140902/68c26090-b308-490b-9021-4f027aad6055.html)）。
2. 链家把同心苑（同心路 232 弄）归入“虹口鲁迅公园”（[链家：同心苑](https://sh.lianjia.com/xiaoqu/5011000004250)）。
3. 恒业路 311 弄也被归入“鲁迅公园”，说明市场不等于公园本体，且向北/西北住宅区延伸（[链家：恒业路 311 弄](https://sh.lianjia.com/xiaoqu/5011000002411)）。
4. 既有四川北路、曲阳、凉城行政骨架分别占据周边街道，鲁迅公园若单独加入，必须从接口区域联合裁切，不能与它们重叠。

**裁定。** 不生成。四川北路、欧阳路、广中路三个 relation 只构成正反例采样包络；不能求并集，也不能把公园边界外扩固定距离。

**共享边。**

- 南侧优先与四川北路联合核四川北路、东江湾路、甜爱路一带；
- 东侧与曲阳联合核大连西路、密云路方向；
- 北侧与凉城联合核广中路、中山北一路方向；
- 每条争议边至少需要一个鲁迅公园正例和一个相邻市场反例后再出线。

### 3.3 东外滩

**证据。**

1. 链家把平凉路 1000、1030、1038、1060、1090 号归入“杨浦东外滩”（[链家：平凉路项目](https://sh.lianjia.com/xiaoqu/5012970675942280)）。
2. 嘉禄公寓（济宁路 29 弄）也归入东外滩，当前核实正例集中在平凉路街道及其滨江方向（[链家：嘉禄公寓](https://sh.lianjia.com/xiaoqu/5011000004669/)）。
3. 杨浦区政府给出的“杨浦滨江重点功能区”约 `15.6 km²`，从秦皇岛路延伸至军工路、闸北电厂，覆盖多个街道和大量非住宅功能，明显不是东外滩住宅市场（[杨浦区政府：杨浦滨江重点功能区](https://www.shyp.gov.cn/zhengwu/zwgk-qzfwj/2025/220/ea2d2053c6de6337ba1ac7992724c6d1.html)）。
4. 政府历史规划中的“东外滩渔人码头文化休闲博览区”是功能区概念，也没有给出可直接复用的住宅市场 polygon（[杨浦区政府：杨浦区总体规划](https://www.shyp.gov.cn/zhengwu/qfb-ztgh/2025/219/39e461dcaf498de30d4e1b2f6aa35a03.html)）。

**裁定。** 不生成。当前只确认“平凉路街道内存在东外滩核心正例”；大桥、定海路 relation 是滨江方向的搜索包络，不代表已经证明市场跨入两街道。

**共享边。**

- 北侧与控江路应从周家嘴路/杨树浦港附近两侧项目归属起查；
- 东侧与定海路不能套用街道共边，因为政府明确平凉路以南是东外滩组成部分，市场边可能切入定海路街道；
- 西侧与北外滩隔黄浦江相望，不应制造跨江共享陆地边；
- 黄浦江岸线可作为南侧自然边，但不能由此推出北、东、西三边。

### 3.4 鞍山

**证据。**

1. 四平路街道官方四至为：东至杨树浦港、南至控江路、西至大连西路/密云路、北至走马塘，面积约 `2.75 km²`（[杨浦区政府：四平路街道简介](https://www.shyp.gov.cn/shypq/yqyw-jd-sp-sqzc-sqjj/20250312/475901.html)）。
2. 政府报道确认鞍山四村居民区由四平路街道治理（[杨浦区政府：鞍山四村](https://www.shyp.gov.cn/shypq/xwzx-jzdt/20230517/428205.html)）。
3. 链家把控江小区（锦西路 100 弄）归入“杨浦鞍山”，页面附近门店地址也明确写“四平路街道”（[链家：控江小区](https://sh.lianjia.com/xiaoqu/5011000004591)）。
4. 彰武路 48 号、飞虹路 740 号、同济绿园（控江路 1888 弄）等已核项目也被卖方归入鞍山，分布覆盖四平路街道多个方向。

**裁定。** 可生成四平路街道 relation 13466002 作为 `low-confidence`、可编辑代理。必须在属性中明确：

```text
marketName = 鞍山
adminProxyName = 四平路街道
method = non_same_name_admin_proxy
confidence = low
```

它不是“同名直用”，也不能升级为卖方边界。

**共享边。**

- 东侧与控江路使用四平路街道—控江路街道固定行政共边作为第一版共享边；
- 北侧与五角场沿走马塘行政共边；
- 西侧虹口曲阳方向沿区界；
- 南侧未来东外滩/江浦方向仍需项目反例，不能因完整四平行政面已生成就视为最终市场线。

### 3.5 定海路

**证据。**

1. 政府给出定海路街道四至：东、南临黄浦江，西界隆昌路、宁武路，北沿周家嘴路、海安路，并明确街道包含复兴岛（[杨浦区政府：定海路街道](https://www.shyp.gov.cn/shypq/sqld-sqjs/20180103/53419.html)）。
2. 同一政府页面明确：内江路以东属于复兴岛开发区域，平凉路以南是东外滩组成部分。这直接否定“完整定海路街道 = 独立定海路住宅市场”。
3. 复兴岛约 `1.133 km²`，少量居住、较多机构和战略留白，不能为铺满地图自动归入同名住宅市场（[杨浦区政府：复兴岛](https://www.shyp.gov.cn/shypq/xwzx-bmdt/20240218/448387.html)）。
4. 链家公开二级市场目录没有“定海路”，本项目相关卖方名是“周家嘴路 → 东外滩”的产品映射。

**裁定。** 不生成市场面。relation 13466400 可以保留为行政参考层，不能登记成定海路卖方市场候选。

**共享边。**

- 与东外滩必须先处理平凉路以南区域；
- 与控江路、黄兴公园方向按周家嘴路、海安路及相邻街道做反例核验；
- 复兴岛、滨江产业和高校/机构用地不能为了零空隙自动塞入定海路市场。

### 3.6 黄兴公园

**证据。**

1. 政府给出黄兴公园精确四至：东营口路、西双阳北路、南走马塘、北国顺东路，占地 `39.86 ha`（[杨浦区政府：黄兴公园](https://www.shyp.gov.cn/zhengwu/wlj-lyzy/2025/219/99a184770fa401b763cecdae792c4444.html)）。
2. 链家把浣纱四村归入“杨浦黄兴公园”（[链家：浣纱四村](https://sh.lianjia.com/xiaoqu/5011000005393)）。
3. 营口路 821 号也归入黄兴公园，说明卖方市场沿公园东侧向住宅延伸（[链家：营口路 821 号](https://sh.lianjia.com/xiaoqu/5020026272204955)）。
4. 长海路街道官方面积约 `9.52 km²`，包含高校、医院、历史建筑和大片非住宅功能；完整街道远大于黄兴公园市场（[杨浦区政府：长海路街道简介](https://www.shyp.gov.cn/shypq/yqyw-jd-wjcz-sqzc-sqjj/20180913/210121.html)）。

**裁定。** 不生成。公园四至作为核心锚点；长海路和延吉新村 relation 只作为周边项目采样包络。不得使用公园面，也不得使用完整长海路街道面。

**共享边。**

- 西侧/西南侧与五角场、鞍山沿走马塘及双阳北路附近联合核验；
- 南侧与控江路、延吉方向不能简单沿周家嘴路一刀切；
- 北侧与中原在民星路、翔殷路一带需要两侧项目反例；
- 公园本体可保留在市场展示外壳内，但属性必须注明它只是地名核心而非住宅项目。

### 3.7 中原

**证据。**

1. 殷行街道政府概况明确称“街道所在的中原地区”，并说明军工路以西由市光、开鲁、国和等七个新村片组成特大型住宅区，军工路以东为大中型企事业单位集聚区（[杨浦区政府：殷行街道基本概况](https://www.shyp.gov.cn/shypq/yqyw-jd-yh-sqzc-sqjj/20211026/395085.html)）。
2. 链家把国和一村归入“杨浦中原”（[链家：国和一村](https://sh.lianjia.com/xiaoqu/5011000011020)）。
3. 殷行路 718 弄、工农三村等已核项目也被卖方归入中原，正例与政府描述的军工路以西住宅区一致。
4. 固定 OSM relation 面积 `9.612949 km²`，而政府当前页面使用 `7.98 km²`；面积口径/边界版本存在明显漂移，完整 relation 不能无条件直用。

**裁定。**

- 不生成完整殷行街道 relation；
- 可生成 `relation 13466582 ∩ 军工路以西` 的 `low-confidence`、可编辑住宅代理；
- 生成器必须使用固定 OSM 道路几何裁切并记录所用道路对象；如果军工路多线或拓扑无法形成稳定裁切面，则退回“不生成”，不得手画直线替代。

**共享边。**

- 西侧与新江湾城优先沿世界路—闸殷路的行政共边；
- 南侧与长海路/黄兴公园优先沿民星路及街道共边，再用市场样本修正；
- 军工路以东产业带暂不分配给任何住宅市场；
- 北侧宝山区界不允许市场自动跨区。

## 四、第一版生成规格

### 4.1 鞍山

```text
sourceGeometry = OSM relation 13466002
status = reviewed-candidate
confidence = low
method = non_same_name_admin_proxy
editable = true
```

必须增加：

- `adminProxyName = 四平路街道`；
- `marketAdminAlignmentUnverified = true`；
- `sharedEdgeReview = 控江路、五角场、东外滩、曲阳`。

### 4.3 拓扑门槛

两项候选生成后必须检查：

1. 几何有效、非空、无自交；
2. 与已注册候选正面积重叠为零；
3. 鞍山与控江路、五角场的行政共享边没有缝隙或重叠；
4. 中原与新江湾城、长海路行政包络没有重叠；
5. 中原的军工路裁切线来自固定 OSM 道路几何，不是人工两点直线；
6. 所有学校、医院、公园、产业、滨江、水域保留/排除规则写入属性；
7. 不因追求行政区铺满而自动填补五个暂不生成市场留下的空白。

## 五、后续精修顺序

1. **先定鞍山—控江路—五角场**：已有稳定街道共边，可快速建立杨浦中西部拓扑。
2. **再定中原—新江湾城—黄兴公园**：先固定中原军工路以西代理，再围绕黄兴公园四至采集周边反例。
3. **再定东外滩—定海路—控江路**：从已核平凉路正例向东、西扩展，不能从 15.6 km² 杨浦滨江功能区向内猜。
4. **最后定瑞虹新城—鲁迅公园**：这两项都需与已经生成的四川北路、曲阳、凉城、北外滩联合移动共享边。

## 六、明确不主张

- 不主张上述 relation 组合是卖方专有边界；
- 不主张行政街道可以无条件替代市场板块；
- 不主张“瑞虹新城 = 嘉兴路街道”；
- 不主张“鲁迅公园市场 = 鲁迅公园本体”；
- 不主张“东外滩 = 杨浦滨江重点功能区”；
- 不主张“定海路街道 = 定海路卖方市场”；
- 不主张“黄兴公园 = 长海路街道”；
- 不主张完整殷行街道 relation 都属于中原住宅市场；
- 不主张零重叠或生成器成功就代表市场边界已经准确。
