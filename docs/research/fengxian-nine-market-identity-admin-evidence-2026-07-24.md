# 奉贤九个市场板块：市场身份与现行行政代理证据

日期：2026-07-24
对象：西渡、南桥、奉贤金汇、海湾、柘林、奉城、四团、青村、庄行

## 结论

1. **九个名称均有独立市场身份。** 链家上海公开网站地图在“奉贤二手房”下同时列出奉城、奉贤金汇、海湾、南桥、青村、四团、西渡、柘林、庄行九个二级市场；同一页的小区和网签目录也重复使用这九个名称。因此它们不是本项目为了凑满行政区而临时发明的标签。[链家上海网站地图](https://sh.lianjia.com/seositemap/)
2. **九个名称也都能一一落到一个现行同名街镇起画骨架。** 截至 2025 年末，奉贤区官方现行口径为 **8 镇、4 街道**；2026 年区政府文件逐项列出南桥、奉城、青村、四团、金汇、柘林、庄行、海湾 8 镇和西渡街道，并把头桥街道单列。[上海市政府：奉贤区](https://www.shanghai.gov.cn/fengxian/index.html)；[奉贤区 2026 年碳达峰碳中和及节能减排重点工作安排](https://www.shanghai.gov.cn/gwk/search/content/00844664)
3. **本批九项全部 `GO`，但只允许生成 `confidence=low` 的可编辑行政代理。** 行政同名只能证明有一个可解释的起画对象，不能证明卖方市场恰好沿街镇边界。全部候选都必须保存 `marketAdminAlignmentUnverified=true`，不得写成“精确卖方边界”“官方楼市板块”或“行业统一边界”。
4. **2026 当前版本的关键变化是头桥街道。** 2024 年市政府批准从奉城镇析出头桥街道，行政区划代码为 `310120004`。所以奉城必须使用 2024-07 之后、已经扣除头桥的现行关系；任何仍把头桥包在奉城内的旧关系都是 `NO-GO`。[上海市政府关于设立奉贤区头桥街道办事处的批复](https://www.shanghai.gov.cn/gwk/search/content/de9f1f55d21246c9836fa54047388fef)；[上海市民政局关于确定头桥街道行政区划代码的函](https://www.shanghai.gov.cn/gwk/search/content/b014447f84f841fca1df65b60fcf087e)
5. 九项中需要额外突出三类歧义：
   - **南桥不等于奉贤新城。** 官方“十五五”纲要所称新城核心承载区跨南桥镇、奉浦街道、金海街道，并含庄行、青村、金汇部分区域。
   - **海湾不自动等于海湾镇。** 官方材料同时、分别存在“海湾镇”和“海湾旅游区”；本批若只用海湾镇，必须把旅游区接口标为未决。
   - **奉贤金汇是市场显示名，正式行政名是金汇镇。** 两字段必须分离，避免与链家目录中徐汇区的“金汇”市场混淆。[奉贤区“十五五”规划纲要](https://www.shanghai.gov.cn/gwk/search/content/00843930)

## 一、证据口径

### 1.1 市场身份

[链家上海网站地图](https://sh.lianjia.com/seositemap/)是链家自己公开发布的站点分类目录，可作为“链家当前把该名称当作奉贤二级市场使用”的第一方证据。它同时列出：

```text
奉城、奉贤金汇、海湾、南桥、青村、四团、西渡、柘林、庄行
```

九个二手房目录路由分别为：

- [奉城](https://sh.lianjia.com/ershoufang/fengcheng/)
- [奉贤金汇](https://sh.lianjia.com/ershoufang/fengxianjinhui/)
- [海湾](https://sh.lianjia.com/ershoufang/haiwan/)
- [南桥](https://sh.lianjia.com/ershoufang/nanqiao/)
- [青村](https://sh.lianjia.com/ershoufang/qingcun/)
- [四团](https://sh.lianjia.com/ershoufang/situan/)
- [西渡](https://sh.lianjia.com/ershoufang/xidu/)
- [柘林](https://sh.lianjia.com/ershoufang/zhelin/)
- [庄行](https://sh.lianjia.com/ershoufang/zhuanghang/)

检索时这些详情路由可能触发链家访问控制，因此可复核入口应以仍能完整列出九项的公开网站地图为主。该目录只证明名称和分类层级存在；本研究没有取得、复制、反推或再分发链家的专有 polygon、坐标或房源全集。

### 1.2 2026 当前行政版本

- [上海市政府奉贤区概况](https://www.shanghai.gov.cn/fengxian/index.html)截至 2025 年末明确写为“辖 8 镇 4 街道”。
- [奉贤区 2026 年碳达峰碳中和及节能减排重点工作安排](https://www.shanghai.gov.cn/gwk/search/content/00844664)的 2026 年街镇任务表逐项列出本批 8 镇、西渡街道以及头桥街道，证明九个代理名在 2026 年仍是现行行政单元。
- [奉贤区 2026 年 1 月公共文化资源配送预告](https://www.shanghai.gov.cn/nw17239/20251231/1090ee561a664d2a80d1d67be7601901.html)同时列出南桥、奉城、四团、金汇、青村、柘林、庄行、海湾 8 镇，西渡、奉浦、金海、头桥 4 街道，并另列海湾旅游区。这为“海湾镇 ≠ 海湾旅游区”提供直接的现行官方旁证。
- [头桥街道设立批复](https://www.shanghai.gov.cn/gwk/search/content/de9f1f55d21246c9836fa54047388fef)给出其四至；上海市政府公开报道进一步明确其为“从奉城镇析出”。因此奉城现行边界必须排除头桥。[上海市政府：析出街道报道](https://www.shanghai.gov.cn/nw4411/20241125/9abe2d32c9074f15bb8755118d8ca385.html?siteId=1)

本研究未发现 2024-07 之后又改变这九个街镇行政身份的市政府批复。实现时仍应以项目锁定快照中最新关系版本为准，并把 `adminBoundaryVersion` 至少约束为 `2024-07-or-later`；这是一条版本门槛，不代表开放数据已自动获得政府认证。

共同裁定的准确含义是：


## 三、名称歧义与相邻空档

### 3.1 南桥与奉贤新城

[奉贤区“十五五”规划纲要](https://www.shanghai.gov.cn/gwk/search/content/00843930)把奉贤新城的“一核”描述为包括南桥镇、奉浦街道、金海街道、庄行镇、青村镇及金汇镇部分区域。这直接否定了以下任一机械等式：

```text
南桥市场 = 奉贤新城
南桥镇 = 奉贤新城
奉贤新城 = 南桥镇
```

因此本批南桥只使用南桥镇代理。奉浦、金海以及相邻三镇中的新城部分既不能被南桥自动吞并，也不能因为未列为目标市场就被视为“不存在”。

### 3.2 海湾镇与海湾旅游区

官方 2026 材料把“海湾镇”和“海湾旅游区”作为两个不同属地单位分别列出；“十五五”纲要也使用“海湾镇、海湾旅游区”并列叙述。链家只给出一个“海湾”市场名，并没有在网站地图公开其市场四至。

所以本批可做的是：

```text
marketName = 海湾
adminName = 海湾镇
confidence = low
unresolvedAdjacency = 海湾旅游区
```

本批不可做的是把海湾镇与旅游区直接合并、用其中任一方声称完整代表链家海湾，或把名称相同当成边界相同的证据。

### 3.3 奉贤金汇与其他“金汇”

链家网站地图在徐汇区另有一个“金汇”市场，在奉贤区则明确使用“奉贤金汇”。因此产品显示名必须保留“奉贤”前缀；正式行政代理仍应保存为“金汇镇”。不要把市场消歧名改写成不存在的“奉贤金汇镇”。

### 3.4 头桥空档

头桥街道是 2026 当前四个街道之一，但不在本项目奉贤九个目标市场清单，也不在链家网站地图的奉贤九个二级市场中。本批正确行为是保留显式空档：

- 不并入奉城；
- 不并入四团、青村或金汇；
- 不把“未被本批市场覆盖”误报成几何错误；
- 若后续要覆盖，必须先研究头桥在卖方口径中的归属或建立独立市场身份。

同理，奉浦街道、金海街道和海湾旅游区没有进入本批九项，不能为了行政全覆盖而静默分配给南桥、奉贤金汇或海湾。

## 四、实现字段与验收门槛

九项第一版统一建议：

```text
status = reviewed-candidate
confidence = low
method = market_admin_candidate_with_shared_topology
marketAdminAlignmentUnverified = true
adminBoundaryVersion = 2024-07-or-later
```

逐项字段：

| `marketName` | `adminName` | 必须风险标记 |
|---|---|---|
| 西渡 | 西渡街道 | `admin_proxy_may_be_broader_than_residential_market` |
| 南桥 | 南桥镇 | `not_equal_fengxian_new_city` |
| 奉贤金汇 | 金汇镇 | `market_admin_name_differ`、`market_name_disambiguated` |
| 海湾 | 海湾镇 | `unresolved_haiwan_tourism_area` |
| 柘林 | 柘林镇 | `admin_proxy_may_be_broader_than_residential_market` |
| 奉城 | 奉城镇 | `post_2024_touqiao_split_required` |
| 四团 | 四团镇 | `lingang_management_not_admin_boundary` |
| 青村 | 青村镇 | `not_equal_fengxian_new_city` |
| 庄行 | 庄行镇 | `not_equal_fengxian_new_city` |

生成必须满足：

1. 九个候选只允许通过严格正式行政名命中，不做模糊匹配；
2. 奉城的开放关系或其他几何输入必须是头桥析出后的版本，并与头桥现行四至保持零正面积重叠；
3. 海湾只使用海湾镇关系，海湾旅游区保持显式未决，不做自动合并；
4. 南桥只使用南桥镇关系，不能从奉贤新城规划范围替换、扩张或裁剪；
5. 奉贤金汇的市场显示名和金汇镇行政名分字段保存；
6. 同批九面几何必须有效、无自交、互相无正面积重叠；共享边应按同一固定快照成组处理；
7. 头桥、奉浦、金海、海湾旅游区允许成为本批未分配空档，不能为铺满地图而分给相邻市场；
8. 对外说明必须分开归因：链家目录证明市场名称存在，政府材料证明行政身份与版本，开放地图关系仅提供可编辑几何候选；
9. 从 `low` 升级前，必须逐块取得多个完整小区正例、相邻市场反例和第二类独立市场证据；名称一致、面积接近或行政共享边均不能单独完成升级；
10. 不得把政府网页或标准地图包装为可下载、可再分发的官方 GeoJSON。

## 六、本研究明确不主张

- 不主张九个行政面就是链家或任何卖方的专有 polygon；
- 不主张链家目录名称能证明边界、完整覆盖或行业共识；
- 不主张同名就意味着市场边界与行政边界相同；
- 不主张南桥镇等于奉贤新城；
- 不主张海湾镇等于链家“海湾”的完整市场范围；
- 不主张现行奉城仍包含头桥；
- 不主张临港管理范围改变了四团镇行政归属；
- 不主张本批九面应覆盖奉贤全部土地；
- 不主张本研究获取、复制、反推或再分发了卖方专有边界数据；
- 不把本地小红书原始帖子、评论或观点样本用作本研究证据。
