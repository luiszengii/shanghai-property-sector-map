# 网上房地产（Fangdi）公开复用许可核查（2026-07-29）

## 结论

截至 **2026-07-29（Asia/Shanghai）**，本次仅从第一方来源确认到：

1. `www.fangdi.com.cn` 的一手房查询是上海市房屋管理局在其“房产交易”栏目中链接的官方查询入口；
2. 上海市房地产交易中心依法/依规负责将新建商品房销售及交易信息提供网上公开查询；
3. 网页页脚标注“Copyright (c) 2011-2018 Shanghai Real Estate Trading Center 版权所有：上海市房地产交易中心”。

**没有找到** Fangdi 或上海市房地产交易中心发布的、明确允许第三方把项目详情页字段进行批量抓取、镜像、再发布、建立衍生数据库或作为稳定 API 使用的公开许可、开放数据协议或下载条款。

因此本项目的保守处理为：**Fangdi 项目页资料可以作为人工事实核验的官方来源，并可在来源说明中放置原页链接；不能仅因页面可公开访问而改判为“可公开引用/可公开投射”，更不能批量把字段写入用户端公开数据集。** 需要取得权利人的书面授权，或改用带有明确开放许可的政府数据源后，再重新裁定。

这是一份产品数据许可核查，不是法律意见；没有找到授权条款不能反推存在授权。

## 四种行为的区分

| 行为 | 本次官方证据 | 本项目当前结论 |
|---|---|---|
| **公开可访问** | 房管局把 Fangdi 的“一手房查询”作为外部官方入口；相关规范要求交易中心提供网上公开查询服务。 | 可以由用户在原站查询；页面有验证码和访问控制，不等于无条件机器访问。 |
| **可链接** | 官方房管局自身以普通超链接指向 Fangdi。未发现禁止链接的第一方声明。 | 可使用原始详情页 URL 作为“官方查询入口”链接，前提是链接不规避验证码/访问控制，也不暗示平台授权转载内容。 |
| **可引用事实** | 交易中心依法公布销售许可、楼盘表及交易信息，并提供公开查询。 | 可用于人工比对、形成内部证据和在内容中说明“据该日期官方查询页显示”。但未发现将字段复制进公开数据库的授权；不要复制页面表达、截图、表格结构或把推算值称为官方均价。 |
| **批量再发布/转载/镜像** | 找到版权归属提示；未找到开放许可、API 文档、批量下载或再利用条款。 | **不允许据此推定许可。** 保持 `仅限事实核验`，不进入公开投射。 |

## 第一方来源与逐条判断

### 1. 上海市房屋管理局“房产交易”栏目

- 来源：[上海市房屋管理局 · 房产交易](https://fgj.sh.gov.cn/fcjy/index.html)
- 观察日期：2026-07-29。
- 页面将“**一手房查询**”直接链接至 `https://www.fangdi.com.cn/new_house/new_house.html`，并在同页提供商品房预售许可证查询等房管服务入口。
- 能证明：Fangdi 是房管局列出的官方查询入口，使用其页面做来源核验具有官方出处。
- 不能证明：房管局/交易中心已向第三方授予字段再利用、批量转载、镜像或 API 调用许可。该页面没有给出这样的授权文本。

### 2. 商品房销售合同网上备案和登记办法

- 来源：[上海市人民政府关于批转市房地资源局制订的《上海市商品房销售合同网上备案和登记办法》的通知](https://www.shanghai.gov.cn/nw12940/20200815/0001-12940_1113.html)
- 关键内容：第五条规定，开发企业取得预售许可证或新建商品房房地产权证后，交易中心通过网上操作系统即时公布许可证/权证、规划平面图、建筑分层平面图和楼盘表等；第十六条规定交易中心定期汇总、分析、发布全市新建商品房交易信息并提供网上公开查询服务。
- 能证明：公开查询的制度基础与数据公开范围；项目页面中的许可、楼盘表、交易类信息可作为一手官方事实核验来源。
- 不能证明：该“公布/公开查询”义务为第三方创设了复制、批量提取、再发布或商业化利用的授权。原文没有明示这些权利。

### 3. Fangdi 项目查询/详情页页脚版权提示

- 来源：[网上房地产 · 一手房查询](https://www.fangdi.com.cn/new_house/new_house.html)；[项目详情页示例](https://www.fangdi.com.cn/new_house/new_house_detail.html?project_id=1482e3a3bd7713ef)
- 观察日期：2026-07-29。通过浏览器正常访问的查询结果及详情页页脚显示：`Copyright (c) 2011-2018 Shanghai Real Estate Trading Center 版权所有：上海市房地产交易中心`。
- 访问说明：从非浏览器环境访问该站会触发 HTTP 400/412 等访问控制；查询页存在图形验证码。此类控制不能被规避。
- 能证明：站点将页面版权归属标注给上海市房地产交易中心，且并非开放 API 页面。
- 不能证明：版权年份覆盖每一项数据事实或数据是否单独构成著作权客体；也不能从该提示单独推出所有链接或合理引用均被禁止。它足以否定“公开网页天然可批量复用”的假设。

### 4. 上海市房地产交易中心的法定职能（背景佐证）

- 来源：[上海市房地产交易中心 2024 年度决算](https://www.shanghai.gov.cn/cmsres/ac/acad83a8e34248b791a5540a62d02d41/acdca6b108143caf374bff29e38a2f83.pdf)
- 关键内容：交易中心为上海市房屋管理局下属单位，职责包括房地产交易和产权日常管理、交易合同网上备案、市场监测分析和新建项目房屋预搭楼盘表。
- 能证明：站点数据由该官方交易管理体系产生/管理的背景，而不是商业看房平台转载。
- 不能证明：任何对外开放数据再利用许可。

## 对当前 MVP 的落地建议

1. **不把 192 条 Fangdi 研究证据批量公开。** 维持来源 `allowedUse=仅限事实核验`、证据 `publicationStatus=待裁定`。
2. 用户端若需要“官方入口”，只显示项目已确认的**外链**，文案写“前往上海网上房地产查询”，不要复制详情页整表、截图、楼栋价格表或库存快照。
3. 若 MVP 要显示项目名、地址、许可证或交易字段，应优先寻找同一事实的、带明确开放数据/再利用许可的政府数据源；否则取得上海市房地产交易中心的书面数据使用授权，并把授权范围、日期、字段和用途记录为来源修订。
4. 即使未来获准公开，也要把项目级即时库存、销售速度、报价等作为带观察日期的快照，避免把历史查询结果表述成“实时”或“官方均价”。
